# Shared editor assets

One copy of each editor-facing asset, consumed by every Extension
(ADR-0066). Edit here; never in a client's private copy.

- `epher.tmLanguage.json`: the TextMate grammar. The baseline spelling
  of the language when no language server is running; the server's
  semantic tokens refine it live. Consumers: `clients/vscode` (as
  JSON, copied by its sync script), `clients/jetbrains` (as plist
  XML in the TextMate bundle), `clients/sublime` (as plist XML,
  generated by its `sync-assets.py`). Zed consumes none of it: Zed
  has no TextMate engine, and rides the server's semantic tokens
  instead.
- `epher-snippets.json`: the snippets. One JSON file in the VS Code
  snippet shape; the language server embeds this same file
  (`crates/lsp/src/analysis.rs` includes it) so editors without a
  snippet engine of their own get them through completion too.

The clients themselves: `clients/vscode` (the pilot),
`clients/jetbrains` (the first-class plugin), `clients/zed` (the
dev-extension), and the ready-made configs `clients/vim`,
`clients/nvim`, `clients/sublime`. Visual Studio follows last.
