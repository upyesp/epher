Privacy

The short version: epher collects nothing. There are no accounts, no analytics, no telemetry, and no advertising.

This website

These pages are static files served by GitHub Pages. The only things stored on your device are two browser preferences — your chosen theme and language — kept in localStorage and never sent anywhere. GitHub, as the host, processes standard request logs; see GitHub's own privacy statement for what that involves.

The web app

The web app runs entirely in your browser: expressions are evaluated locally, and your work stays in the page's session. Installing it for offline use changes nothing — there is still no network call behind your back.

Desktop, command line, and terminal

The installed apps keep everything in one folder on your machine — saved functions, constants, scripts, history, and your language preference. Delete that folder and every trace is gone. Nothing is ever uploaded.

Questions

If anything here is unclear or wrong, please open an issue on GitHub and it will be fixed.
