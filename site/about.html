About epher

epher is a programmable, scriptable calculator: one calculation engine with five ways to use it — a one-shot command, an interactive session, a full-screen terminal UI, and a desktop app with an offline web app alongside. The same functions, scripts, and history follow you between all of them.

One engine, honestly reported

The calculator refuses to guess. Errors name the real cause, numbers are binary floats by default with exact fraction, decimal, and big-integer layers one call away, and graphs are computed by the same engine that evaluates your expressions. Every design decision is recorded in the repository as an architecture decision record.

Accessibility is a feature, not a setting

The interface targets WCAG 2.2 AA: keyboard-only use everywhere, visible focus, contrast that clears the thresholds, touch targets sized for fingers, and animation that steps instead of moves when the system asks for reduced motion. The whole product ships in eight languages, including full right-to-left support for Arabic.

Built in the open

epher is free and open source under the MIT license. The source, the issue tracker, and the release downloads live on GitHub.
