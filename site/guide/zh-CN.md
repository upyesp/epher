# epher 用户指南

欢迎！epher 是一款可编程、可脚本化的计算器。你可以用它做快速计算，也可以构建自己的函数和小程序。所有功能都支持八种语言。

本指南面向完全初学者。它从最简单的计算开始，逐步深入到语言的完整功能。每个示例都显示你输入的内容以及 epher 的回应。

epher 有五种使用方式。选择最适合你的那一种：

| 版本 | 是什么 | 何时选用 |
|---|---|---|
| **命令行**（CLI） | 终端中的文本命令 | 常驻终端、喜欢脚本 |
| **REPL** | `epher>` 提示符下的交互式 `epher` 会话 | 想要快速往返，无需离开终端 |
| **终端界面**（TUI） | 终端内的全屏程序 | 想要带图表和屏幕历史的终端应用 |
| **桌面应用** | 带独立窗口的常规桌面程序 | 想要一个常规应用程序 |
| **网页应用**（PWA） | 在浏览器中运行，可安装，可离线使用 | 想最快开始；无需安装 |

桌面应用、命令行、REPL 和终端界面是同一个程序：一次下载安装的 `epher` 命令能完成这四件事。网页应用是例外：完全无需下载。

五个版本理解完全相同的语言。学会一次，随处可用。

## 1. epher 语言

本章讲解所有 epher 版本共享的语言。在网页应用或桌面应用中，输入表达式并按**回车**（或点击 **=** 按钮）。在 CLI 中，用 `epher repl` 启动会话，然后在 `epher>` 提示符后输入。在 TUI 中（`epher tui`），直接输入并按**回车**。在 CLI 中你也可以输入 `epher "表达式"` 直接计算一个表达式。

### 1.1 你的第一个计算

输入：

```epher
2 + 3 * 4
```

epher 回答：

```text
14
```

乘法和数学中一样先于加法计算。这个规则称为*运算符优先级*。

### 1.2 运算顺序

完整的优先级顺序，从强到弱：

1. `!` 阶乘和 `%` 百分比（均为后缀）
2. `^` 乘方
3. `*` 和 `/` 乘法和除法
4. `+` 和 `-` 加法和减法

用括号改变顺序：

```epher
(2 + 3) * 4
```

```text
20
```

`^` 运算符计算乘方，并且从右向左结合：

```epher
2 ^ 10
```

```text
1024
```

```epher
2 ^ 3 ^ 2
```

```text
512
```

（`2 ^ 3 ^ 2` 表示 `2 ^ (3 ^ 2)`，即 `2 ^ 9` = 512。）

乘方可以是分数。`2 ^ 0.5` 就是 2 的平方根：

```epher
2 ^ 0.5
```

```text
1.41421356237
```

减法和除法从左向右计算：

```epher
10 - 3 - 2
```

```text
5
```

`%` 符号是一个后缀运算符，意思是“除以 100”：`5%` 即 0.05。它从不看周围的运算符，所以 `200 + 10%` 是 200.1。要把 200 增加 10%，请写出乘法：

```epher
200 * (1 + 10%)
```

```text
220
```

### 1.4 比较与逻辑

你可以比较数字。结果是 `true`（真）或 `false`（假）：

| 比较 | 含义 |
|---|---|
| `a > b` | a 大于 b |
| `a < b` | a 小于 b |
| `a >= b` | a 大于或等于 b |
| `a <= b` | a 小于或等于 b |
| `a == b` | a 等于 b（注意是两个 `=`） |
| `a != b` | a 不等于 b |

```epher
3 > 2
```

```text
true
```

```epher
1 != 2
```

```text
true
```

用 `and`、`or` 和 `not` 组合比较：

```epher
3 > 2 and 2 < 3
```

```text
true
```

```epher
not 3 > 2
```

```text
false
```

### 1.5 变量

用一个 `=` 给值命名：

```epher
x = 5
```

```text
5
```

epher 会把值重复给你。从现在起，`x` 可以随处使用：

```epher
x ^ 2
```

```text
25
```

你可以随时更改变量。它一直保持自己的值，直到你更改它：

```epher
x = x + 1
```

```text
6
```

> 名称可以包含字母和下划线，如 `radius` 或 `my_total`。不能包含空格，也不能以数字开头。

特殊变量 `ans` 始终保存上一个答案，就像口袋计算器的 `Ans` 键，
适合连续计算：

```epher
2 + 3
ans * 2
```

```text
5
10
```

### 1.6 常量：永不改变的名称

*常量*是一个值永不改变的名称，就像内置的 `pi`，但由你自己选择。用 `const`
定义：

```epher
const tax = 0.2
```

```text
0.2
```

在任何可以使用数字的地方都可以使用它：

```epher
100 * (1 + tax)
```

```text
120
```

这个值是固定的：用 `=` 修改它会报错，

```epher
tax = 0.25
```

```text
error: cannot assign to constant tax
```

用不同的值重新定义同一个常量同样会报错：

```epher
const tax = 0.25
```

```text
error: constant already defined: tax
```

常量与变量还有一个不同之处：和 `pi` 一样，它可以在你自己的函数里使用。

```epher
const g = 9.81
```

```text
9.81
```

```epher
def weight(m) = m * g
```

```epher
weight(80)
```

```text
784.8
```

像保存函数一样，用 `save tax` 把常量保存到以后的会话（第 4.4 章）。

> 变量和常量不能共用一个名称：`const tax = 0.2` 之后，`tax = ...` 永远是
> 错误。换一个新名称，或开始一个新的会话。

### 1.7 字符串与 print

字符串是双引号中的文本：`"hello"`。字符串用 `+` 拼接，用 `==` 和 `!=` 比较，用 `len` 计数，并像列表一样从 1 开始索引：

```epher
"hello" + " " + "world"
len("hello")
"hello"[1]
"abc" == "abd"
```

```text
hello world
5
h
false
```

没有转义序列：字符串里不能出现双引号。**str(x)** 按答案面板的方式写出一个值，**print(a, b, …)** 把参数用空格连成一行：

```epher
print("x =", 42)
```

```text
x = 42
```

### 1.8 用 if 做判断

`if` 在两个值之间选择：

```epher
if 3 > 2 then 10 else 20
```

```text
10
```

形式永远是 `if 条件 then 为真时的值 else 为假时的值`。`else` 部分必不可少。

带变量的更有用示例：

```epher
price = 100
if price > 50 then 2 else 1
```

```text
100
2
```

> `if` 现在也能比较字符串（见 1.7 节）：两支只要求同类的值：
> 数字对数字，字符串对字符串。

### 1.9 用 while 循环

只要条件成立，`while` 就重复执行一条语句：

```epher
x = 0; while x < 5 do x = x + 1; x
```

```text
0
5
```

把这个脚本读作：*x 从 0 开始；当 x 小于 5 时，给 x 加 1；然后显示 x。*结果是 5，因为循环执行了五次。

> **安全网：** epher 会在 100 000 步之后停止任何循环并显示 `error: step limit exceeded`。这能保护你免受永不结束的循环的困扰。如果看到这个错误，说明你的条件可能永远不会变成假。

### 1.10 用 for 循环

`for` 对每个值重复一次语句，并把语句的值收集成一个列表：可以遍历 `start to end` 区间（含端点，可带 `step`），也可以遍历列表的元素：

```epher
for i in 1 to 5 do i^2
for x in {2, 3, 4} do 10*x
for i in 0 to 1 step 0.5 do i
```

```text
{1, 4, 9, 16, 25}
{20, 30, 40}
{0, 0.5, 1}
```

循环变量在结束后保留最后的值，和 TI 的 For 一样。配合 print，循环能写出可读的行：

```epher
for i in 1 to 3 do print("line", i)
```

```text
{line 1, line 2, line 3}
```

与 while 一样，10 万步的安全网同样限制 for 循环。


### 1.11 用 def 定义自己的函数

函数是带有名称和参数的计算：

```epher
def f(x) = x ^ 2
```

然后使用它：

```epher
f(7)
```

```text
49
```

函数可以有多个参数：

```epher
def area(w, h) = w * h
area(3, 4)
```

```text
12
```

也可以定义没有参数的函数：

```epher
def answer() = 42
answer()
```

```text
42
```

### 1.12 递归：调用自身的函数

最著名的例子是斐波那契数列：

```epher
def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
```

```epher
fib(10)
```

```text
55
```

`fib(10)` 是第 10 个斐波那契数。函数用更小的参数调用自己，直到达到 `n <= 1`。这能成立是因为 `if ... then ... else ...` 形式只计算它需要的分支。

> 函数体是一个单独的表达式，一行。需要组合多个计算时，改用 `;` 写成脚本（见下一节）。

### 1.13 脚本：一次执行多条语句

*脚本*是用 `;` 连接或者用换行符连接，两者含义完全相同，依次执行的若干语句：

```epher
x = 10; y = x + 5; x + y
```

```text
10
15
25
```

脚本是构建小程序的方式：设置变量、循环、显示最终结果。

换行符和 `;` 是同一个分隔符，可以自由混用。多行示例上方的 **复制** 按钮会复制整个脚本，你可以直接把它粘贴到 epher 中：网页应用和桌面应用的输入框、终端界面，以及 `epher repl` 都会按顺序逐行执行，就像你逐行输入一样。用 `;` 在一行中连接多条语句在任何地方同样有效，包括单次计算命令行（第 4.1 节）。


脚本可以带**注释**：写给你自己、由 epher 跳过的笔记，写法与 PHP 相同。`//` 或 `#` 注释到行尾，`/* ... */` 注释一个块。关于某条语句的注释放在这条语句的末尾、`//` 之后，绝不放在语句中间：

```epher
// a small script with notes
r = 3 # radius in metres
area = pi * r ^ 2 // pi r squared
area
```

A block comment may also span several lines. A script file or a pasted
program arrives as one whole program, so its block comments may span
lines:

```epher
/* the area of a circle
   of radius 3 */
pi * 3 ^ 2
```

Input that arrives line by line - typing into the REPL or the terminal
UI, or a piped script - takes one line at a time, so there a block
comment opens and closes on the same line.
### 1.14 精确结果：frac、dec 和 big

通常 epher 像袖珍计算器一样用小数计算，结果像袖珍计算器那样
四舍五入到十二位有效数字：`0.1 + 0.2` 是 `0.3`，绝不会是
`0.30000000000000004`。精确分数默认开启——能还原为小分母分数且
小数部分循环的结果会以分数显示。`1 / 3` 无需询问就显示为
`1/3`：

```epher
1 / 3
```

```text
1/3
```

在结果设置（第 2.2 章）中**关闭精确分数**后，同样的除法显示
`0.333333333333`。**frac(n, d)** 生成精确分数，并在计算过程中保持
精确：

```epher
frac(1, 3)
```

```text
1/3
```

分数在计算过程中保持精确：

```epher
frac(1, 3) * 3
```

```text
1
```

**dec(x)** 生成精确小数。`0.1 + 0.2` 两种设置下都显示 `0.3`——差别
在于运算本身：

```epher
0.1 * 3 - 0.3
dec(0.1) * 3 - dec(0.3)
```

```text
0.0000000000000000555111512313
0.0
```

浮点结果带有每台计算机处理小数时都会产生的微小舍入误差；`dec()`
让运算保持精确。

**big(x)** 生成精确整数，用于超出袖珍计算器范围的数值：

```epher
big(10 ^ 20)
```

```text
100000000000000000000
```

**数制**按数学界的写法书写整数：`0b` 表示二进制，`0o` 表示八进制，`0x`
表示十六进制（前缀只改变拼写，从不改变值）：

```epher
0b1010 + 0xFF
```

```text
265
```

用 **bin(x)**、**oct(x)** 和 **hex(x)** 转回去。它们给出一个整数的带前缀拼写，
可以直接再次使用：

```epher
hex(255)
bin(10)
```

```text
0xff
```
0b1010
```

**exact(x)** 还原小数结果背后的精确分数：任何能构成小分母好分数的值都会这样显示。这正是各应用默认使用的还原方式，所以 `1 / 3` 通常直接显示为 `1/3`：

```epher
exact(0.3333333333333333)
exact(0.30000000000000004)
```

```text
1/3
3/10
```

像 `pi` 这样的无理数没有好的分数，所以 `exact()` 保持原样。

显示动词用另一种记数法书写数字。**scientific(x)** 在指数前用一位数字，**engineering(x)** 用步长为 3 的指数（尾数保持在 1 到 1000 之间），**grouped(x)** 用细空格作为千位分隔符：

```epher
scientific(12345)
engineering(12345)
engineering(0.5)
grouped(1234567.89)
```

```text
1.2345e4
12.345e3
500e-3
1 234 567.89
```

网页应用和 TUI 也把这些作为显示设置提供（见第 2.2 和 5.2 章）：精确分数开或关、自动/科学/工程记数法，以及千位分隔符。这些设置只改变结果的显示方式；底层的值仍然是普通十进制数。

### 1.18 复数

epher 自动用复数计算。虚数单位是 **i**，与 `pi` 完全一样：

```epher
i ^ 2
sqrt(-1)
```

```text
-1
i
```

用 `i` 后缀写复数，无需乘号：`3 + 4i` 是一个字面量，`2.5i` 可用，带基数的字面量（`0xFFi`）也可以。通常的运算随之扩展：加、减、乘、除、乘方都有效，`i` 遵循正常的优先级（`i ^ 2` 与任何乘方一样结合）。

实数函数也随之扩展。给定复数参数时它们在复平面中计算；给定超出实数定义域的实数参数时，它们返回主值复数结果而不是报错：

```epher
ln(-1)
asin(2)
exp(i * pi)
```

```text
3.14159265359i
1.57079632679-1.31695789692i
-1+0.000000000000000122464679915i
```

（`exp(i * pi)` 恰好是 `-1`；末尾几位是计算机算术中 `sin(pi)` 的噪声。）

四个函数读取复数的各个部分，`abs()` 是它的模：

```epher
re(3 + 4i)
im(3 + 4i)
arg(-1)
conj(3 - 4i)
abs(3 + 4i)
```

```text
3
4
3.14159265359
3+4i
5
```

仅整数的函数（`fact`、`gcd`、`floor`、`isprime`……）会以类型错误拒绝复数参数。

### 1.19 解方程

**solve** 求一元方程的根。方程使用 `==`：

```epher
solve x^2 == 5*x + 6
```

```text
x = -1, x = 6
```

多项式方程（由 `+ - * ^` 和常量构成）给出全部根，包括实根和复根：

```epher
solve x^2 == -1
solve x^2 + 2*x + 5 == 0
solve (x - 1)^2 == 0
```

```text
x = -i, x = i
x = -1-2i, x = -1+2i
x = 1
```

要求解的变量是 `x`（当它出现时），否则是唯一的另一个变量。常量和已绑定的变量作为参数：

```epher
const k = 3
solve k*x == 12
```

```text
3
x = 4
```

任何其他方程都会在 -100..100 上做数值扫描：通过符号变化括出根，所以 `solve sin(x) == 0.5` 会列出该范围内的每一个根。两个坦诚的限制：函数只触及零点的根（如数值路径下的 `x^2 == 0`）可能被漏掉，含多个未绑定变量的方程会报错。

### 1.20 微积分：导数与积分

**derivative(expr, p)** 是 `expr` 在 `p` 处的数值导数。第一个参数保持为表达式，其自由变量就是被求导的变量：

```epher
derivative(x^2, 3)
derivative(sin(t), 0)
```

```text
6
1
```

因为参数保持为表达式，导数可以绘图：`graph derivative(x^3 - x, x)` 绘制斜率曲线。

**integral(expr, a, b)** 是从 `a` 到 `b` 的定积分，用自适应辛普森求积计算：

```epher
integral(x^2, 0, 3)
integral(sin(x), 0, pi)
```

```text
9
2
```

`integral(x^2, 3, 0)` 是 `-9`（带符号的积分），可绘制的上限同样有效：`graph integral(x^2, 0, x)`。

两者都是数值计算；表达式在区间内必须取实数值，含多个变量的表达式会报错。

### 1.21 数据：列表、统计与回归

列表是大括号中的一列数字：`{1, 2, 3}`。元素是表达式，允许空列表
`{}`，列表可以像任何值一样绑定到名称：

```epher
d = {12, 15, 14, 16, 13, 15, 14, 17}
d[2]
len(d)
```

`list[i]` 是第 i 个元素，从 1 开始计数，与计算器一致；索引越界是
错误。方括号比 `^` 绑定更紧，所以 `d[2]^2` 是 `(d[2])^2`。

对列表的运算是逐元素进行的，单个数字会广播到每个元素：

```epher
{1, 2, 3} * 2
{1, 2, 3} + 10
```

两个列表做 `+ - * / ^` 运算时长度必须相同。`==` 和 `!=` 比较整个
列表；排序比较不接受列表。

统计函数接受一个列表作为唯一参数（多参数形式保留——`mean(1, 2,
3)` 仍然可用）：`sum product mean median mode variance stdev min max
range`。新的形态函数有 `len(列表)`、`sort(列表)`（升序副本）、
`mode(列表)`（出现最多的值，并列时取最小）、`range(列表)`（最大
减最小）和 `quartile(列表, k)`（k 为 1..3，TI 式四分位，取两半的
中位数）：

```epher
mean(d)
median(d)
quartile(d, 1)
```

**linreg(xs, ys)** 对两个等长列表拟合最小二乘直线，并连同相关系数
r 一起报告：

```epher
linreg({1, 2, 3, 4}, {2.1, 4.2, 5.8, 8.1})
```

拟合直线是一种显示结果，就像 solve 的根；拟合的图形在散点图上
（第 1.23 节）。

回归家族的其余部分拟合计算器长大后用到的模型：**quadreg** 拟合 `y = a*x^2 + b*x + c`（至少 3 个点），**expreg** 拟合 `y = a*e^(b*x)`（y > 0），**powreg** 拟合 `y = a*x^b`（x、y > 0），**logreg** 拟合 `y = a + b*ln(x)`（x > 0）。每个都连同 r 报出模型：

```epher
quadreg({1, 2, 3, 4}, {1, 4.1, 8.9, 16.2})
expreg({1, 2, 3}, {2.7, 7.4, 20.1})
```

```text
y = 1.05*x^2 + -0.21*x + 0.2 (r = 0.9999)
y = 0.9911*e^(1.0037*x) (r = 1)
```

变换拟合的 r 是线性化后数据对的相关系数，与 TI 和 NumWorks 报出的数字相同。每个模型也能在散点图上自绘：`graph scatter(xs, ys, quadreg)`（或 expreg、powreg、logreg）会连同该模型的曲线一起画出各点。

### 1.22 分布与假设检验

概率函数覆盖标准正态、t、卡方、二项和泊松分布族。正态族接受一个
或三个参数——一个参数即标准正态：

```epher
normcdf(1.96)
invnorm(0.975)
normcdf(12, 10, 2)
```

`normpdf(x[, mu, sigma])`、`normcdf(x[, mu, sigma])`、`invnorm(p[,
mu, sigma])`；`tpdf(x, df)`、`tcdf(x, df)`、`invt(p, df)`；
`chi2pdf(x, df)`、`chi2cdf(x, df)`、`invchi2(p, df)`；
`binompdf(k, n, p)`、`binomcdf(k, n, p)`；`poissonpdf(k, lambda)`、
`poissoncdf(k, lambda)`。`inv*` 函数回答相反的问题：`invt(0.975,
10)` 是下方有 97.5% 质量的 t 值。

检验函数接受一个数据列表，以显示文本报告统计量和双侧 p 值；区间
函数在您指定的水平上报告 `(下, 上)`：

```epher
d = {12, 15, 14, 16, 13, 15, 14, 17}
ttest(d, 14)
tinterval(d, 0.95)
ztest(d, 14, 1.5)
chisq_gof({20, 30, 25, 25}, {25, 25, 25, 25})
```

```text
{12, 15, 14, 16, 13, 15, 14, 17}
t = 0.8819, p = 0.4071
(13.1594, 15.8406)
z = 0.9428, p = 0.3458
chi2 = 2, p = 0.5724
```

`ttest(数据, mu0)` 和 `tinterval(数据, 水平)` 使用样本标准差
(n−1)；`ztest(数据, mu0, sigma)` 和 `zinterval(数据, sigma, 水平)`
需要已知的 sigma。`chisq_gof(观测值, 期望值)` 是自由度为 k−1 的拟
合优度检验。结果是显示文本：可读、可复制，但算术不能使用它们。

还有两个同形的检验。**anova(列表1, 列表2, …)** 是对两组或更多组的单因素方差分析（长度不等也可以），连同 p 值报出 F：

```epher
anova({1, 2, 3}, {4, 5, 6}, {7, 8, 9})
```

```text
F = 27, p = 0.001
```

**ttestpaired(a, b)** 是配对 t 检验：取两条等长列表的差，对 0 做检验，课堂上的"前后"对比：

```epher
ttestpaired({80, 85, 90}, {82, 84, 91})
```

```text
t = -0.7559, p = 0.5286
```

太阳系一样——最新命令胜出，`graph clear` 清空它。

```epher
x = {1, 2, 3, 4, 5}
y = {2.1, 4.2, 5.8, 8.1, 9.9}

```

```epher
graph histogram({1, 2, 2, 3, 3, 3, 4, 5})
```

```epher

```

**scatter(xs, ys)** 绘制点，当点数不少于两个时绘制最小二乘拟合
直线，图例标注为 `y = a*x + b (r = …)`。**histogram(数据[,
组数])** 绘制频率直方图；组数可选（默认使用斯特吉斯规则），必须是
1 到 50 之间的整数。**boxplot(数据)** 绘制箱线图：最小值、Q1、

### 1.24 随机数

`random()` 抽取 `[0, 1)` 中的均匀随机数，`random(a, b)` 抽取 `[a, b)` 中的一个，
`randint(a, b)` 抽取闭区间 `[a, b]` 中的一个整数——掷骰子：

```epher
randseed(7)
randint(1, 6)
```

```text
7
3
```

序列是可复现的：`randseed(n)` 用 `n` 重新设定随机种子并显示它，因此相同的种子
在每个会话、每个前端都会重放相同的抽取结果。

**randn(mu, sigma)** 从均值为 mu、标准差为 sigma 的正态分布中抽值（Desmos 叫 randomNormal，TI 叫 randNorm）：

```epher
randseed(7)
randn(0, 1)
```

```text
7
1.36499229746
```

同一种子重放同样的抽取，与均匀分布完全一致。

### 1.25 单位与换算

数字后跟单位就成为一个*量*：SI 单位的值加上它的量纲。单位表涵盖 SI
基本单位和导出单位（`m`、`s`、`kg`、`A`、`K`、`mol`、`cd`、`Hz`、`N`、
`Pa`、`J`、`W`、`C`、`V`、`F`、`ohm`、`S`、`Wb`、`T`、`H`、`lm`、`lx`、
`Bq`、`Gy`、`Sv`）、日常单位（`min`、`hr`、`d`、`yr`、`L`、`t`、`bar`、
`atm`、`torr`、`psi`、`eV`、`mile`、`yd`、`ft`、`inch`、`nmi`、`lb`、
`oz`、`gal`、`qt`、`pt`、`mph`、`knot`）以及第 1.29 节的天文后缀。
复合单位可以串联：`60 mile/hr` 和 `5 m/s^2` 都是单个单位。

```epher
60 mile/hr
```

```text
60 mile/hr
```

SI 词头可以缩放任意单位：`k M G T m µ n p` 是千、兆、吉、太、毫、微、
纳、皮——`5 km`、`3 MPa`、`1 GHz` 都可以，`2 kg` 就是千克本身。

量纲会被检查：不同单位的量相加或比较会报错，而不是混在一起算：

```epher
5 m + 3 s
```

```text
error: dimension error: cannot add 5 m and 3 s
```

算术会组合量纲：`5 m * 3 m` 是 `15 m^2`，`(3 m)^2` 是 `9 m^2`，
`sqrt(4 m^2)` 是 `2 m`，量纲完全相消的整个表达式又回到普通数字
（`5 m / 5 m` 是 `1`）。量纲恰好匹配时，结果优先使用导出名称——
`5 kg * 3 m / 1 s^2` 得出 `15 N`。

**换算。** `expr in 单位`（或 `expr -> 单位`）以指定单位显示一个量；
量纲必须匹配。`in` 的绑定最松，所以 `5 m + 3 m in km` 换算的是整个和：

```epher
72 km/hr in m/s
```

```text
20 m/s
```

```epher
2 m^2 in cm^2
```

```text
20000 cm^2
```

温度标度（摄氏、华氏）在这里不是单位——开尔文是，`K` 和其他单位一样用。


### 1.26 位运算

第 1.15 节的基本字面量就是为此而生的：`0b101`、`0o17`、`0xFF`。位运算符
作用于整数，返回精确的整数：

```epher
0xFF & 0x0F
```

```text
15
```

| 运算符 | 含义 |
|---|---|
| `a & b` | 按位与 |
| `a \| b` | 按位或 |
| `a xor b` | 按位异或 |
| `~a` | 按位取反（二进制补码） |
| `a << n` | 左移（乘以 2^n） |
| `a >> n` | 右移，算术移位（除以 2^n，向下取整） |

结果都是精确的 `big` 整数，所以 `1 << 60` 保留每一位数字。默认字长为
64 位：结果按有符号二进制补码解读，因此 `~0` 是 -1，`1 << 100` 回绕为
0。`bits(n)` 把字长改为 8、16、32 或 64，`bits()` 报告当前值：

```epher
bits(8)
~0
```

```text
8
-1
```

负数移位会反向（`8 << -1` 是 `4`）。布尔 `and` 和 `or` 保持原意；
`&` 和 `|` 是位运算写法。


### 1.27 隐式关系

含两个未知数的等式可以画成曲线：图形家族用移动方块采样该关系并绘制其零等高线。圆、抛物线和竖直线各一条命令：

```epher
graph x^2 + y^2 == 1
```

```epher
graph y == x^2
```

```epher
graph x == 2
```

关系在 `from a to b`（或默认窗口）给出的正方形上采样，所以 `graph x^2 + y^2 == 1 from -2 to 2` 正好框住圆。曲线能做的它都能做：图例标注等式，滑块驱动其常量，画面可以缩放、平移、导出。不等式填充（`y < …`、`y > …`）仍是带阴影的曲线；关系没有感兴趣点。


### 1.28 矩阵

矩阵是数字的网格，写成列表的行：`[[1, 2], [3, 4]]` 是 2×2 矩阵。`+` 和
`-` 逐元素运算（形状须相同），`*` 是矩阵乘法，数字逐元素缩放，`^` 是整数
次矩阵幂（`A ^ 0` 是单位阵，所以幂需要方阵）。`M[2][1]` 是第 2 行第 1
列的元素——行像列表一样从 1 开始索引。

```epher
[[1, 2], [3, 4]] * [[5, 6], [7, 8]]
```

```text
[[19, 22], [43, 50]]
```

矩阵函数覆盖课堂需求：`det(M)`（仅方阵）、`inv(M)`（奇异矩阵报错）、
`transpose(M)`、`trace(M)`（方阵）、`dim(M)`（`{行, 列}` 列表），以及
`ref(M)` 与 `rref(M)` 行化简。线性方程组通过增广矩阵的 rref 求解：

```epher
rref([[2, 1, 5], [1, -1, 1]])
```

```text
[[1, 0, 2], [0, 1, 1]]
```

各行读出 `x = 2`、`y = 1`——即化简后增广矩阵的最后一列。精确分数像
列表一样显示在矩阵里，所以 `inv([[1, 2], [3, 4]])` 显示
`[[-2, 1], [3/2, -1/2]]`。


### 1.29 天文与太阳系

epher 会说天文语言：单位后缀、物理常数、历法和时间函数，以及为太阳、月球、
行星和冥王星提供的实时星历。一切均可离线使用。

**会说天文的单位。** 在数字后面写一个单位后缀，epher 会立即把它换算成 SI 单位：

| 后缀 | 单位 | 换算为 |
|---|---|---|
| `AU` 或 `au` | 天文单位 | 米 |
| `pc` | 秒差距 | 米 |
| `ly` | 光年 | 米 |
| `deg` | 度 | 弧度 |
| `arcmin`, `arcsec` | 角分、角秒 | 弧度 |
| `min`, `hr`, `d`, `yr` | 分、小时、日、儒略年 | 秒 |
| `Jy` | 央斯基 | W m-2 Hz-1 |

```epher
3.2 AU in m
```

```text
478713186240 m
```

```epher
sin(30 deg)
```

```text
0.5
```

后缀属于语法的一部分：任何用户常量都不能改变 `3.2 AU` 的含义，而 `h` 仍然是
普朗克常数；小时写作 `hr`。函数返回自然单位的数值；后缀把数值换算成 SI，
因此 `mag2jy(20)` 是以央斯基计的数值，而 `mag2jy(20) Jy` 是以瓦每平方米赫兹
计的同一流量。

**天文常数。** `au`、`pc`、`ly`、`c`、`g`、`h`、`h_bar`、`k_b`、`sigma_sb`、
`m_sun`、`r_sun`、`l_sun`、`m_earth`、`r_earth`、`m_moon`、`r_moon` 的用法与 `pi` 相同，你也可以
用自己的常量遮蔽它们。

**日期与时间。** `jd(y, m, d [, hr])` 和 `mjd(...)` 把日历日期换算为儒略日，
`now()` 读取当前时刻：

```epher
jd(2000, 1, 1, 12)
```

```text
2451545
```

`delta_t(jd)` 是 TT - UT1 修正，`lst(jd, lon)` 是东经经度（以度计）对应的
当地恒星时（以小时计）。

**时分秒。** `hms2deg(h, m, s)` 把赤经换算为度，`dms2deg(d, m, s)` 换算六十
进制角，`deg2hms(x)` / `deg2dms(x)` 把角度以文本形式写回：

```epher
deg2hms(90)
```

```text
6h 0m 0s
```

**量化天空。** 每个访问函数都要给出天体编号：水星 1、金星 2、火星 4、木星 5、
土星 6、天王星 7、海王星 8、冥王星 9、太阳 10、月球 11（地球是 3，是观测者，
永远不是目标）。

| 函数 | 含义 |
|---|---|
| `ra(b, jd)`, `decl(b, jd)` | 地心赤经和赤纬（度） |
| `dist(b, jd)` | 距离（天文单位） |
| `alt(b, jd, lat, lon)`, `az(b, jd, lat, lon)` | 站心高度角和方位角（度，真值） |
| `rise(b, jd, lat, lon)`, `set(...)`, `transit(...)` | 当地太阳日内的事件，以儒略日表示 |
| `mag(b, jd)` | 视星等 |
| `phase(b, jd)`, `illum(b, jd)` | 相位角（度）和照亮比例 |
| `diam(b, jd)` | 角直径（度） |

```epher
decl(10, jd(2000, 6, 21, 1.8))
```

```text
23.437882351
```

纬度和经度以度计，东为正。除非给出观测者，位置均为地心坐标。冥王星使用
近似轨道，精度约为一角分，远低于其他天体；不包含日食月食和合星搜索。

**光学与光度。** `kepler(M, e)` 求解开普勒方程，`airmass(alt)` 是 sec(z)
大气质量，`dawes(d)` 是 d 毫米口径的分辨本领（角秒），`dist_mod(mu)` 把
距离模数换算为秒差距。

**季节。** `march_equinox(year)`、`june_solstice(year)`、
`september_equinox(year)` 和 `december_solstice(year)` 返回每个季节节点的
儒略日：

```epher
march_equinox(2000)
```

```text
1012520636/413
```

**三维太阳系。** `solar3d` 命令画出整个太阳系：每条轨道是一条曲线，每个
天体是一个带标签的圆点，并带有显示它刚经过位置的轨迹：

```epher
solar3d jd(2020, 7, 1)
```

把时间写成一个常量，然后按下播放键，就能看到行星运动：
`const t = now(); solar3d t`。拖动或用方向键旋转视角，`clear` 清空，
`solar3d save file.svg` 导出。

星历由 solar-ephemeris crate（github.com/Protonmatter/sol）计算，并经
JPL Horizons 验证；感谢其作者。在当前前后约 5000 年内，太阳、月球和行星的
精度为角秒级。

### 1.30 金融

货币时间价值求解器（TI 符号约定：现金流出为负、流入为正）在给定其余
四个字段时求解五个字段中的任意一个。`i` 是每期利率的小数——0.01 即 1%——
可选的最后一个参数是付款时点：0 为期未（默认），1 为期初（期初年金）。

```epher
tvm_pmt(360, 0.08/12, -100000, 0)
```

```text
733.764573879
```

经典 8% 房贷：360 期每月 733.76 的还款对应 100,000 贷款——`tvm_pmt`
是每期付款，`tvm_pv` 是贷款额，`tvm_fv` 是余额，`tvm_n` 是期限，
`tvm_i` 是利率：

```epher
tvm_i(360, -100000, 733.76, 0)
```

```text
0.00666661199068
```

这里的利率略低于 8%/12，因为 733.76 是四舍五入的。`npv(r, flows)` 折现
现金流列表，`irr(flows)` 求净现值为零时的利率：

```epher
npv(0.1, {-100, 60, 60})
```

```text
500/121
```

`amort(p, r, n, k)` 是 n 期贷款第 k 次还款后的剩余余额，
`simple_interest(p, r, t)` 是 `p*r*t`，`compound_interest(p, r, n)`
是 `p*(1+r)^n - p`。

## 2. 网页应用（PWA）

### 2.1 打开它

网页应用位于：

```text
https://epher.org/pwa/
```

无需安装。它在任何现代浏览器中都能运行，无论是电脑、手机还是平板。

本指南也内置在应用中：打开菜单栏中的 **Help → In-app user guide**（在手机上点击 **☰**），即可在应用内以应用当前的语言阅读。点击该指南中的任何示例，即可将其载入输入框。 **帮助 → 常量**打开常量浏览器：全部内置常量按组显示（数学、天文、物理、化学），每个都带值和简短说明；点按一个即可把它的名称插入输入框，搜索框可以筛选列表。

### 2.2 你的第一个计算

1. 点击文本框（页面加载时它已经获得焦点）。
2. 输入表达式，例如 `2 + 3 * 4`。
3. 按**回车**或点击 **=** 按钮。

结果以大号文字显示在输入框下方。第 1 章的所有内容在这里都适用，包括变量、函数和脚本。简短的单个答案留在这一行。较长的答案 - 包含多个答案的脚本输出、表格或长数字 - 显示在结果面板（即同时显示图形的面板）中，每个答案占一行；在手机上面板会自动滑入视野。 答案左侧有一个复制图标 - 按下它，答案的值就会进入剪贴板，每行一个；结果面板中的长答案也以同样方式复制。

输入名称时会自动出现建议列表：方向键移动高亮，**Enter** 或 **Tab** 接受，**Esc** 关闭，点击也可接受且无需离开键盘。每条建议都带有函数或常量的简短说明。**F1** 在键盘上方的提示条中显示光标处词语的同样说明。如果在一个空输入行中首先输入的是运算符（`+ - * / ^ % !`），epher 会自动插入 `ans`，让该行从上一个答案继续。

屏幕键盘替你输入，效果与按下按键完全相同。它的分组覆盖整个语言：`123` 数字与运算符、`trig`、`ƒ` 函数、`nΣ` 数字与统计、`data` 矩阵、列表和字符串（负责输入 `[[1, 2], [3, 4]]`、`{1, 2, 3}` 和 "text" 的分组）、`0x` 转换与进制、`dist` 回归与分布族、`$` 财务、`π∇` 常量与绘图命令，以及 `☉` 天文（唯一可滚动的分组）。本指南中的每个函数都在某个按键上。打开 **key hints**（**?** 按钮）可为每个按键加注说明，或停留在某个按键上阅读其作用。

**设置**菜单（齿轮图标，或在手机上 **☰ → 设置**）包含三组。**主题**和**语言**名副其实。**结果**决定答案的显示方式：精确分数（默认开启，因此 `1 / 3` 显示为 `1/3`）、记数法（自动、科学或工程）和千位分隔符。这些只是显示设置；底层的值仍是普通数字。

### 2.3 历史记录

每次计算都会添加到结果下方的历史列表中，你可以回看自己做过什么。最新的条目显示在顶部，**历史**标题左侧的垃圾桶图标可以清空它（终端里是 Ctrl+L，或点击同一个图标）。历史记录在页面打开期间保留。

每个条目之间以细线分隔：单行表达式占一行，多行脚本则是一个显示其全部行的条目。点击某个条目即可将其加载回输入框并重新运行。

### 2.4 绘图

输入 `graph` 加一个表达式，然后按**回车**：

```epher
graph x ^ 2
```

epher 在带标签坐标轴的网格上，从 x = −10 到 x = 10 绘制曲线 y = f(x)，位于输入框下方。你可以绘制任何表达式，包括自己的函数：

```epher
def f(x) = x ^ 3
graph f(x)
```

每行 `graph` 都会在同一张图中添加一条曲线，每条曲线有自己的颜色。所有曲线都是实线，图例和曲线端点的标注才是不靠颜色区分它们的方式。`graph clear` 会清空图形，图形面板顶部的 **Clear graph** 按钮会同时清空曲线和 3D 曲面。TUI 在 **Graph** 菜单中保留了这条命令。

在图形面板顶部，**Clear graph**、**Copy SVG** 和 **Save PNG** 旁边，工具栏可以隐藏关注点列表和绘制在图形上的标记点。每个图形正上方都有一条由图标命名的滑块条，说明文字在各自的提示框里：线条粗细（2D 曲线用 0 到 4、步长 0.1 的滑块，3D 图形用 0 到 0.4、步长 0.05 的滑块，默认 0.2 - 只显示当前图形类型的滑块，每种类型各自记住自己的值）；每种图形还有缩放滑块，3D 和太阳系视图另有水平与垂直旋转速度。按下某个滑块的图标会把它重置为默认值。图例中的每一项前面都有一个复选框，默认勾选：取消勾选会把曲线、3D 曲面、空间曲线或太阳天体从图形、它的关注点和 SVG 导出中隐藏。

```epher
graph x ^ 2
graph x ^ 3
```

表达式没有值的点（例如除以零）会被跳过，在曲线中留下空隙。而实际上是垂直渐近线的跳跃永远不会画成连接线。

#### 2.4.1 可以绘制什么

自选定义域：

```epher
graph sin(x) from 0 to 2*pi
```

参数曲线（t 从 0 到 2π）：

```epher
graph param 2*cos(t), 3*sin(t)
```

极坐标曲线：

```epher
graph polar 1 + cos(theta)
```

区域：`y <` 为曲线下方区域着色，`y >` 为上方着色：

```epher
graph y < x ^ 2
```
#### 2.4.2 读懂图形

**追踪：** 将指针移到图形上，或将焦点放在图形上并按箭头键。曲线上最近的点会被标记，其坐标显示在图形下方。

**关注点：** 每次执行 graph 命令后，epher 会找出每条曲线的根和转折点以及曲线之间的交点，在图形上标记出来，并列在图形下方：

```text
root (-1, 0)   minimum (0, 0)   root (1, 0)
```

**表格：** `table` 命令会打印数值表（表达式没有值的行留空）：

可选的 `derivative <表达式>` 子句添加第三列，即该表达式在每个
x 处的数值导数：

```epher
table x ^ 2 from -2 to 2 points 5 derivative x ^ 2
```

```text
         x           y          y'
        -2           4          -4
        -1           1          -2
         0           0           0
         1           1           2
         2           4           4
```

表格单元格遵循结果设置：启用精确分数（默认）时，是简单分数的值
会以分数显示——`table x / 3 from 0 to 1 points 4` 列出 `1/3` 而不是
`0.333`。
```epher
table x ^ 2 from -2 to 2 points 5
```

```text
         x           y
        -2           4
        -1           1
         0           0
         1           1
         2           4
```

还有两个子句覆盖剩下的工作。`values <列表>` 用数据列表充当 x 列，而不是等距网格：把数据交给它，看它变换：

```epher
d = {1, 2, 3, 4, 5}
table x ^ 2 values d
```

```text
         x           y
         1           1
         2           4
         3           9
         4          16
         5          25
```

`exact` / `approx` 则为这一张表强制单元格的显示：`exact` 在凑得准时显示简单分数，`approx` 显示小数；各自只对这一条命令覆盖结果设置。

#### 2.4.3 滑块与导出

定义一个常量并在图形中使用它，图形下方就会出现一个滑块。拖动它（或用箭头键移动它），每条曲线都会重绘：

```epher
const a = 1
graph a * x ^ 2
```

每种图形都以同样的方式缩放：在它上面滚动鼠标滚轮（或在触摸屏上捏合）即可放大缩小，图形上方的缩放滑块会随之移动。数据图（散点图、直方图和箱线图）与曲线图完全一样可以缩放。

**复制 SVG** 把当前图形复制为自包含的 SVG 图片，方便粘贴到文档中。颜色已内嵌，背景透明，因此可以放到任何页面、幻灯片或文档上。**保存 PNG** 把同一张图以两倍大小保存为位图，曲线保持清晰，背景同样透明；桌面版会询问保存位置，浏览器版保存到下载文件夹（或按浏览器的支持情况询问）。滑块行和动画常量位于图形正下方、关注点列表上方。动画滑块是真正的控件：抓住它的指示器拖到新值（抓取会先停止动画），或在它获得焦点时用方向键微调。

#### 2.4.4 3D 曲面

`graph3d` 在正方形定义域（−5 到 5，或你的 `from a to b`）上绘制曲面 z = f(x, y)：

```epher
graph3d x ^ 2 - y ^ 2
```

离你更近的网格线画得更深，形状因此更有纵深感。多条 `graph3d` 行会像曲线一样叠加在同一张图中，`graph3d clear` 会清空图形。拖动可以旋转视图，或将焦点放在图形上并用箭头键旋转。终端界面把同一个曲面绘制成 ASCII 线框图，用箭头键旋转它。

空间曲线用 `param` 画：`graph3d param cos(t), sin(t), t` 在你给的 t 范围上（`from 0 to 6.28318`）画一条螺旋线，默认 0 到 2pi。同一个面板，同样的旋转、缩放和动画。
#### 2.4.5 动画

每个滑块都有一个播放按钮。它让滑块对应的常量在滑块范围内逐步变化并循环：指示器走完整条轨道，到达终点后回到起点。这是计算器做动画的标准方式：你让一个参数动起来，所有用到它的东西都会跟着动。再次按下按钮就会暂停。

“时间”变量不过是你动画化的一个常量：

```epher
const t = 0
graph sin(x - t)
```

播放 t 的滑块会让波形移动。3D 曲面同样可以动画化。先定义一个常量，然后播放它的滑块：

```epher
const a = 1
graph3d sin(a * (x ^ 2 + y ^ 2)) from -3 to 3
```

在终端界面中，空格键开始和停止动画。

### 2.5 安装与离线使用

网页应用是一个*渐进式网页应用*：访问一次后即可完全离线使用，还可以像普通应用一样安装。

- **Chrome、Edge 或 Android：** 点击地址栏中的安装图标（或浏览器菜单中的*安装应用*），然后确认。
- **iPhone / iPad（Safari）：** 点击**分享** → **添加到主屏幕**。
- **其他浏览器：** 在菜单中查找*安装*或*添加到主屏幕*。

安装后，从主屏幕或应用列表启动它。即使没有网络连接也能瞬间打开。

### 2.6 网页应用不能做什么

网页应用把你的工作保留在当前会话中：它计算表达式、绘制图形（第 2.4 节）并保留历史记录。**save**、**save script** 和 **language** 命令在桌面、命令行和终端版本中可用（第 3、4、5 章）。在网页应用中，它们会回复一条说明：保存功能在那些版本中可用。最近的活动会被记住 - 历史、变量、函数和最后一个答案在关闭应用后依然保留，只保存在这个浏览器里。

## 3. 桌面应用

桌面应用是同一个网页应用外面的普通窗口。第 2 章的内容全部适用；区别只在于安装和启动方式。

### 3.1 安装

从 epher 网站为你的系统下载一个安装程序：

- **Windows：** 运行 `epher-windows-x86_64.exe`。安装程序会把 `epher` 加入你的 PATH。打开一个新的 CMD 或 PowerShell 窗口，`epher "2 + 2"` 即可使用。由于构建未签名，首次启动请选择*更多信息* → *仍要运行*。
- **macOS：** 打开 `epher-macos-aarch64.dmg` 并把 epher 拖入应用程序文件夹。由于构建未签名，首次启动需要右键 → **打开**。
- **Linux（Debian/Ubuntu）：** `.deb` 包

```sh
sudo apt install ./epher-linux-x86_64.deb
```

- **Linux（Fedora/RHEL）：** `.rpm` 包

```sh
sudo dnf install ./epher-linux-x86_64.rpm
```

- **Linux（任何发行版，包括 Arch）：** AppImage。赋予执行权限并运行：

```sh
chmod +x epher-linux-x86_64.AppImage
./epher-linux-x86_64.AppImage
```

每个安装程序都包含*完整*的 epher：桌面应用、命令行（第 4 章）和终端界面（第 5 章），全部是同一个 `epher` 命令。在 Linux 上，软件包会把 `epher` 安装到 `/usr/bin`。

### 3.2 使用

像启动其他任何应用一样启动 epher。你会看到一个与网页应用界面相同的窗口：输入表达式，按**回车**或点击 **=**，然后阅读结果。绘图在这里同样有效。`graph x ^ 2` 会在窗口中绘制（第 2.4 节）。窗口可以自由调整大小。菜单栏包含 **Help → In-app user guide**，与本页相同的指南，其中的示例点击即可载入。

你也可以从终端打开它：不带参数的 `epher`（或 `epher gui`）会启动桌面应用。在 macOS 上，使用应用内的**安装 epher 命令**按钮，把 `epher` 放到终端 PATH 中。

### 3.3 存储：与 CLI 和 TUI 共用同一个存储

桌面应用与命令行和终端版本共用存储。函数、常量、脚本、历史记录和语言偏好存放在同一个地方，你电脑上的 `~/.epher`（或 `EPHER_STORE_DIR`，见第 4.6 节），在一个版本中保存的所有内容都可以在其他版本中使用：

```text
def area(w, h) = w * h
save area
```

在桌面应用中定义 `area`，用 `save` 保存，关闭窗口。然后打开 CLI，`area(3, 4)` 直接可用。反过来也一样：打开桌面窗口时，在 CLI 或 TUI 中保存的函数和脚本已经在那里了，包括保存的脚本设置的变量。第 4 章的 `save`、`save script` 和 `language` 命令在这里的用法完全相同。

你在 CLI、REPL、TUI 或桌面应用中输入的命令都会加入同一份历史记录，会话也会随之迁移：你赋值的变量和 `ans` 值会从一个版本跟随你到下一个版本。共享存储是实时的：当两个版本同时打开时，一个版本中的更改会立即反映到另一个版本中（桌面应用和 TUI 会监视存储并自动刷新）。

> 浏览器中的网页应用是唯一不使用这个存储的版本。每次会话相互独立（第 2.6 节）。

## 4. 命令行（CLI）

CLI 是与桌面应用同一个 `epher` 程序的文本一面。它有三种模式：单次计算、管道脚本，以及用于较长时间工作的交互式会话。

随时可以获得帮助：运行 `epher --help`（所有命令和示例），或
`epher help`（完整手册；在 Linux 安装包上就是 `man epher` 手册页）。

每个安装程序都自带整个脚本合集 —— 也就是网站 Scripts 页面浏览的那些脚本
—— 并把它们安装到程序旁边。网站上、脚本 README 中以及下文里可以复制的终
端命令都指向这个安装好的文件夹，所以只要装好 epher，它们就能直接运行：

```sh
# Debian, Ubuntu, Fedora (deb, rpm)
epher /usr/lib/epher/scripts/astronomy/moon/full-moons.epher

# Windows (PowerShell)
epher "$env:LOCALAPPDATA\epher\scripts\astronomy\moon\full-moons.epher"

# macOS
epher /Applications/epher.app/Contents/Resources/scripts/astronomy/moon/full-moons.epher
```

### 4.1 单次计算

把表达式作为参数传入：

```sh
epher "2 + 3 * 4"
```

```text
14
```

第 1 章中任何单一表达式都可以：

```sh
epher "if 3 > 2 then 10 else 20"
```

```text
10
```

以减号开头的表达式可以直接使用：

```sh
epher "-2 + 5"
```

```text
3
```

单次模式用于脚本，从单个表达式一直到整个程序。每条语句的值各占一行打印：

```sh
epher "x = 10; x + 5"
```

```text
10
15
```

在参数中用换行符连接的语句同样有效。第 1 章的所有内容都可用：变量、函数、循环，一切。而且各行共享同一个会话，就像管道脚本一样（第 4.2 节）。

### 4.2 管道脚本

`epher -` 从标准输入逐行读取表达式，就像脚本语言在管道中的用法：

```sh
# Linux and macOS (bash, zsh)
printf "x = 3\nx * 10\n" | epher -

# Windows PowerShell
"x = 3`nx * 10" | epher -
```

```text
= 3
= 30
```

第 1 章的所有内容都可以用，而且各行共享同一个会话：前面定义过的函数后面可用，`save` 照常写入同一个存储。出错会打印出来，脚本继续运行。一行可以用 `;` 连接多条语句。换行符和 `;` 在 epher 中处处含义相同。


文件也是同样的用法：`epher plots/sine.es` 按顺序执行文件的每一行并打印每个结果。当参数命名一个已存在的文件且包含 `.`、`/` 或 `\` 时，它会被当作文件 - 所以 `epher x` 仍然对名字 `x` 求值。
### 4.3 交互式会话（REPL）

用 `epher repl` 启动：

```sh
epher repl
```

> 不带参数的 `epher` 会打开桌面应用（第 3 章）。

epher 显示提示符并等待：

```text
epher>
```

现在逐行输入第 1 章中的任何内容。变量在行与行之间保持值：

```text
epher> x = 5
= 5
epher> x ^ 2
= 25
```

`table` 命令（第 2.4.2 节）在这里同样会打印数值表：

```text
epher> table x ^ 2 from -2 to 2 points 5
         x           y
        -2           4
        -1           1
         0           0
         1           1
         2           4
```

每个答案显示为 `= 结果`。输入 `quit`（或 `exit`）退出：

```text`graph` 行在这里同样可用：曲线会跨行累加，`graph save plot.svg` 会写出
与网页应用**复制 SVG**按钮相同的 SVG 图片。`graph3d save file.svg`
也以同样方式保存 3D 曲面。同样的 graph 行在单次求值和管道脚本中都能用：
`epher "graph sin(x); graph save plot.svg"` 一条命令就是一个完整的图形。


epher> quit
```

你的历史记录会被记住：下次运行 `epher repl` 时，上一次会话的输入仍然在。


`load` 命令逐行运行一个脚本 - 文件路径，或者用 `save script` 保存的脚本名 - 就像你亲手输入的一样：

```text
epher> load plots/sine.es
epher> load my_setup
```
### 4.4 保存函数、常量和脚本

定义一个函数，然后保存它：

```text
epher> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
epher> save fib
saved fib
```

`save fib` 命令把函数存到磁盘。下次启动会话时，`fib` 已经定义好了：

```text
epher> fib(10)
= 55
```

常量的保存方式相同。对常量名使用 `save`：

```text
epher> const tax = 0.2
= 0.2
epher> save tax
saved tax
```

要保存整个脚本（你输入的最后一行），使用 `save script`：

```text
epher> x = 0; while x < 5 do x = x + 1; x
= 5
epher> save script count_to_five
saved script count_to_five
```

保存的脚本会在 epher 启动时自动运行，所以它们定义的一切都为你准备好了。


你也可以随时用 `load count_to_five` 载入已保存的脚本，或把它留作普通文件并运行 `load count_to_five.es`；`epher count_to_five.es` 则直接在命令行运行它（第 4.2 节）。
### 4.5 更改界面语言

界面语言取自你设备上设置的语言。要覆盖它，输入 `language` 加下列之一：`en`、`zh-CN`、`hi`、`es`、`fr`、`ar`、`de`、`pt`：

```text
epher> language fr
language set to fr
```

选择会被记住，供下次使用。注意：你*输入*的语言（表达式语言）始终相同，与界面语言无关。

### 4.6 数据存放在哪里

函数、脚本、历史记录和语言选择存放在你电脑上的一个文件夹中：

```text
~/.epher
```

删除该文件夹即可完全重新开始。要使用其他位置，请在启动 epher 前设置环境变量 `EPHER_STORE_DIR`：

```sh
EPHER_STORE_DIR=/tmp/my-epher epher repl
```

## 5. 终端界面（TUI）

TUI 是交互式会话的全屏版本，运行在终端内。它与桌面应用同属一个 `epher` 程序。用以下命令启动：

```sh
epher tui
```

### 5.1 屏幕

屏幕分为几个面板：

- **Expression**（表达式）：输入框（顶部）。Shift+Enter 开始新的一行；方向键或鼠标点击在文本中移动光标。
- 下方的当前**结果**。
- **History**（历史）：你输入的每一行及其答案。
- **Graph**（图表）：`graph` 命令绘制的图形（底部）。
- 提示行显示键盘快捷键。

### 5.2 按键

| 按键 | 作用 |
|---|---|
| 输入 | 在光标处添加到表达式 |
| **回车** | 计算整个脚本（多行输入作为一个历史记录项运行） |
| **Shift+Enter** | 开始新的一行 |
| **← → ↑ ↓** | 移动光标（输入为空时：旋转 3D 图形） |
| **Esc** | 清空输入行 |
| **F1** | 描述光标处的函数（显示在结果行） |
| **Ctrl+C** | 退出 |
| **q** | 退出（输入为空时） |
| **Arrow keys** | 旋转 3D 视图（输入为空时） |
| **Space** | 开始/停止动画（输入为空时） |
| **F10** | 打开菜单（File、Edit、Graph、Settings、Help） |
| **Tab** | 聚焦始终显示的键盘（或从键盘进入历史）；切换分组（**Esc** 返回输入） |
| **鼠标** | 点击菜单及菜单项、键盘按键与分组标签、历史行（载入表达式）；拖拽图形面板旋转（3D）或平移（2D），滚轮缩放，双击重置视图 |
| **Ctrl+L** | 清空历史 |

**帮助**菜单打开应用内指南、键盘按键帮助，以及常量浏览器：内置常量按组显示，方向键选择一行，**回车**把它的名称插入光标处的表达式，**Esc** 关闭。

键盘的分组涵盖语言支持的全部函数、常量和命令：**trig**、**fn**、**num**、**0x**、**var**。0x 分组包含精确数与进制转换（`frac`、`dec`、`big`、`bin`、`oct`、`hex`）以及阶乘 `!`。方向键移动高亮，**Enter** 插入记号，**Tab** 切换分组。 在空行开头输入（或从键盘插入）运算符时，会先自动补上 `ans`，该行便从上一个答案继续。

**设置**菜单提供与网页应用相同的结果显示选项（精确分数、记数法、千位分隔符），与主题和语言行并列。

### 5.3 绘图

输入 `graph` 加一个表达式，然后按**回车**：

```epher
graph x ^ 2
```

epher 在 x = −10 到 x = 10 之间取样曲线，并以 ASCII 图形绘制在 Graph 面板中；图形上方的图例标注所绘内容。

`graph clear` 会清空图形，**Graph** 菜单也能做同样的事；**Help** 菜单会在 TUI 内打开本指南（方向键滚动，**Esc** 关闭）。**Settings** 菜单可以隐藏图形下方列出的关注点。

你可以绘制任何表达式，包括自己的函数。先定义一个，再绘制它：

```epher
def f(x) = x ^ 3
graph f(x)
```

每行 `graph` 都会为图形添加一条曲线，用各自的符号（`o`、`x`、`+`、`*`）绘制；`graph clear` 会清空图形。与网页应用相同的语法同样适用：定义域（`graph sin(x) from 0 to 2*pi`）、参数曲线（`graph param 2*cos(t), 3*sin(t)`）、极坐标曲线（`graph polar 1 + cos(theta)`）和区域（`graph y < x ^ 2` 为曲线下方区域着色）。

表达式没有值的点（例如除以零）会被直接跳过，在图中留下空隙。每次执行 graph 命令后，TUI 都会在图形下方列出关注点（根、转折点和交点）。`table` 命令（第 2.4.2 节）在这里同样有效。

`graph3d x ^ 2 - y ^ 2` 把 3D 曲面绘制成 ASCII 线框图。输入为空时用方向键旋转它，按空格键让滑块常量动起来（第 2.4.5 节）。底部的提示行只在显示 3D 曲面或可动画曲线时才显示方向键和空格提示。

`graph save plot.svg` 会把当前图形写为与网页应用**复制 SVG**按钮相同的
SVG 图片；`graph3d save file.svg` 会从你当前查看的角度保存 3D 线框。

### 5.4 保存与持久化

TUI 与 CLI 共享存储：在其中一个保存的内容在另一个中同样可用。函数、脚本、历史记录和语言偏好存放在 `~/.epher`（第 4.6 节），`save`、`save script` 和 `language` 命令在这里同样有效。

## 6. 你的数据与隐私

- **已安装的 epher 程序**（桌面应用、CLI 和 TUI）把函数、脚本、历史记录和语言选择本地存放在 `~/.epher`（或 `EPHER_STORE_DIR`）。不会离开你的电脑。
- **网页应用** 不往磁盘写任何东西：历史记录只在页面打开期间有效。网页应用可以离线运行，因为页面本身由你的浏览器存储。

五个版本都在你的设备上完成全部计算。不会向任何地方发送任何内容。
