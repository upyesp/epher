# epher उपयोगकर्ता गाइड

स्वागत है! epher एक प्रोग्राम करने योग्य, स्क्रिप्ट करने योग्य कैलकुलेटर है। आप इसका उपयोग त्वरित गणना के लिए कर सकते हैं, या अपने स्वयं के फ़ंक्शन और छोटे प्रोग्राम बना सकते हैं। सब कुछ आठ भाषाओं में उपलब्ध है।

यह गाइड पूर्ण शुरुआती लोगों के लिए है। यह सबसे सरल संभव गणना से शुरू होता है और भाषा की पूरी शक्ति तक क्रमशः आगे बढ़ता है। हर उदाहरण दिखाता है कि आप क्या टाइप करते हैं और epher क्या उत्तर देता है।

epher का उपयोग करने के पाँच तरीके हैं। जो आपको सबसे उपयुक्त लगे उसे चुनें:

| संस्करण | यह क्या है | कब चुनें |
|---|---|---|
| **कमांड लाइन** (CLI) | टर्मिनल में टेक्स्ट कमांड | आप टर्मिनल में रहते हैं और स्क्रिप्ट पसंद करते हैं |
| **REPL** | `epher>` प्रॉम्प्ट पर एक इंटरैक्टिव `epher` सत्र | टर्मिनल छोड़े बिना त्वरित आदान-प्रदान चाहते हैं |
| **टर्मिनल इंटरफ़ेस** (TUI) | टर्मिनल के अंदर एक फुल-स्क्रीन प्रोग्राम | ग्राफ़ और स्क्रीन पर इतिहास वाला टर्मिनल ऐप चाहते हैं |
| **डेस्कटॉप ऐप** | अपनी विंडो वाला एक सामान्य डेस्कटॉप प्रोग्राम | एक सामान्य एप्लिकेशन चाहते हैं |
| **वेब ऐप** (PWA) | आपके ब्राउज़र में चलता है, इंस्टॉल हो सकता है, ऑफ़लाइन काम करता है | सबसे तेज़ शुरुआत चाहते हैं; कोई इंस्टॉलेशन नहीं |

डेस्कटॉप ऐप, कमांड लाइन, REPL और टर्मिनल इंटरफ़ेस एक ही प्रोग्राम हैं: एक डाउनलोड से `epher` कमांड इंस्टॉल होता है, जो चारों काम करता है। वेब ऐप अपवाद है: उसे कोई डाउनलोड नहीं चाहिए।

पाँचों संस्करण बिल्कुल एक ही भाषा समझते हैं। एक बार सीखें, कहीं भी उपयोग करें।

## 1. epher भाषा

यह अध्याय epher के सभी संस्करणों में साझा भाषा सिखाता है। वेब ऐप या डेस्कटॉप ऐप में, एक व्यंजक टाइप करें और **Enter** दबाएँ (या **=** बटन पर क्लिक करें)। CLI में, सत्र `epher repl` से शुरू करें और `epher>` प्रॉम्प्ट के बाद टाइप करें। TUI में (`epher tui`), बस टाइप करें और **Enter** दबाएँ। CLI में आप एक व्यंजक सीधे मूल्यांकित करने के लिए `epher "व्यंजक"` भी लिख सकते हैं।

### 1.1 आपकी पहली गणना

यह टाइप करें:

```epher
2 + 3 * 4
```

epher उत्तर देता है:

```text
14
```

गुणा जोड़ से पहले होती है, बिल्कुल गणित की तरह। इस नियम को *ऑपरेटर प्राथमिकता* कहते हैं।

### 1.2 संक्रियाओं का क्रम

पूर्ण प्राथमिकता क्रम, सबसे मज़बूत से सबसे कमज़ोर:

1. `!` क्रमगुणित
2. `^` घात
3. `*` और `/` गुणा और भाग
4. `+` और `-` जोड़ और घटाव

क्रम बदलने के लिए कोष्ठक का उपयोग करें:

```epher
(2 + 3) * 4
```

```text
20
```

`^` ऑपरेटर घात निकालता है और दाएँ से बाएँ काम करता है:

```epher
2 ^ 10
```

```text
1024
```

```epher
2 ^ 3 ^ 2
```

```text
512
```

(`2 ^ 3 ^ 2` का अर्थ है `2 ^ (3 ^ 2)`, यानी `2 ^ 9` = 512.)

घात भिन्नात्मक हो सकती है। `2 ^ 0.5` मतलब 2 का वर्गमूल:

```epher
2 ^ 0.5
```

```text
1.4142135623730951
```

घटाव और भाग बाएँ से दाएँ काम करते हैं:

```epher
10 - 3 - 2
```

```text
5
```

### 1.3 विशेष संख्याएँ pi, e, tau और phi

प्रसिद्ध स्थिरांक पहले से मौजूद हैं:

```epher
pi
```

```text
3.141592653589793
```

```epher
2 * pi
```

```text
6.283185307179586
```

```epher
e
```

```text
2.718281828459045
```

दो और: `tau` एक पूरा चक्र है (2 pi) और `phi` स्वर्ण अनुपात है:

```epher
tau
```

```text
6.283185307179586
```

```epher
phi
```

```text
1.618033988749895
```

### 1.4 तुलना और तर्क

आप संख्याओं की तुलना कर सकते हैं। परिणाम `true` (सत्य) या `false` (असत्य) होता है:

| तुलना | अर्थ |
|---|---|
| `a > b` | a, b से बड़ा है |
| `a < b` | a, b से छोटा है |
| `a >= b` | a, b से बड़ा या बराबर है |
| `a <= b` | a, b से छोटा या बराबर है |
| `a == b` | a, b के बराबर है (दोहरा `=` ध्यान दें) |
| `a != b` | a, b के बराबर नहीं है |

```epher
3 > 2
```

```text
true
```

```epher
1 != 2
```

```text
true
```

तुलनाओं को `and`, `or` और `not` से जोड़ें:

```epher
3 > 2 and 2 < 3
```

```text
true
```

```epher
not 3 > 2
```

```text
false
```

### 1.5 चर (variables)

एक `=` से किसी मान को नाम दें:

```epher
x = 5
```

```text
5
```

epher मान आपको दोहराकर दिखाता है। अब से `x` का उपयोग कहीं भी किया जा सकता है:

```epher
x ^ 2
```

```text
25
```

आप किसी चर को कभी भी बदल सकते हैं। यह अपना मान तब तक रखता है जब तक आप बदलते नहीं:

```epher
x = x + 1
```

```text
6
```

> नामों में अक्षर और अंडरस्कोर हो सकते हैं, जैसे `radius` या `my_total`। इनमें रिक्त स्थान नहीं हो सकते और ये संख्या से शुरू नहीं हो सकते।

विशेष चर `ans` में हमेशा पिछला उत्तर रहता है, जैसे जेबी कैलकुलेटर की
`Ans` कुंजी, जुड़ी हुई गणनाओं के लिए उपयोगी:

```epher
2 + 3
ans * 2
```

```text
5
10
```

### 1.6 स्थिरांक: कभी न बदलने वाले नाम

*स्थिरांक* एक ऐसा नाम है जिसका मान कभी नहीं बदलता, जैसे बिल्ट-इन `pi`,
लेकिन आपकी पसंद का। इसे `const` से परिभाषित करें:

```epher
const tax = 0.2
```

```text
0.2
```

जहाँ कोई संख्या चल सकती है, वहाँ इसका उपयोग करें:

```epher
100 * (1 + tax)
```

```text
120
```

मान निश्चित है: इसे `=` से बदलना एक त्रुटि है,

```epher
tax = 0.25
```

```text
error: cannot assign to constant tax
```

और एक ही स्थिरांक को दो बार परिभाषित करना भी:

```epher
const tax = 0.25
```

```text
error: constant already defined: tax
```

स्थिरांक चर से एक और तरह से अलग हैं: `pi` की तरह, वे आपके अपने फ़ंक्शन
के भीतर काम करते हैं।

```epher
const g = 9.81
```

```text
9.81
```

```epher
def weight(m) = m * g
```

```epher
weight(80)
```

```text
784.8000000000001
```

किसी स्थिरांक को आने वाले सत्रों के लिए सहेजने के लिए `save tax` करें, ठीक
फ़ंक्शन की तरह (अध्याय 4.4)।

> एक चर और एक स्थिरांक एक ही नाम नहीं रख सकते: `const tax = 0.2` के बाद,
> `tax = ...` हमेशा त्रुटि है। नया नाम चुनें या नया सत्र शुरू करें।

### 1.7 if से निर्णय

`if` दो मानों के बीच चुनाव करता है:

```epher
if 3 > 2 then 10 else 20
```

```text
10
```

रूप हमेशा होता है `if शर्त then सत्य_वाला_मान else असत्य_वाला_मान`। `else` भाग अनिवार्य है।

चर के साथ एक अधिक उपयोगी उदाहरण:

```epher
price = 100
if price > 50 then 2 else 1
```

```text
2
```

> epher में टेक्स्ट मान नहीं हैं: `if` की दोनों शाखाएँ संख्याएँ (या तुलनाओं के परिणाम) होनी चाहिए।

### 1.8 while से लूप

जब तक शर्त सत्य है, `while` एक कथन को दोहराता है:

```epher
x = 0; while x < 5 do x = x + 1; x
```

```text
5
```

इस स्क्रिप्ट को ऐसे पढ़ें: *x को 0 से शुरू करें; जब तक x 5 से छोटा है, x में 1 जोड़ें; फिर x दिखाएँ।* परिणाम 5 है क्योंकि लूप पाँच बार चला।

> **सुरक्षा जाल:** epher किसी भी लूप को 100 000 चरणों के बाद रोक देता है और `error: step limit exceeded` दिखाता है। यह आपको ऐसे लूपों से बचाता है जो कभी समाप्त नहीं होंगे। यदि यह दिखे, तो शायद आपकी शर्त कभी असत्य नहीं हुई।

### 1.9 def से अपने स्वयं के फ़ंक्शन

फ़ंक्शन नाम और पैरामीटर वाली एक गणना है:

```epher
def f(x) = x ^ 2
```

फिर इसे उपयोग करें:

```epher
f(7)
```

```text
49
```

फ़ंक्शन कई पैरामीटर ले सकते हैं:

```epher
def area(w, h) = w * h
area(3, 4)
```

```text
12
```

आप बिना पैरामीटर के भी फ़ंक्शन बना सकते हैं:

```epher
def answer() = 42
answer()
```

```text
42
```

### 1.10 पुनरावृत्ति: अपने आप को बुलाने वाला फ़ंक्शन

सबसे प्रसिद्ध उदाहरण हैं फ़िबोनाची संख्याएँ:

```epher
def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
```

```epher
fib(10)
```

```text
55
```

`fib(10)` दसवीं फ़िबोनाची संख्या है। फ़ंक्शन अपने आप को छोटे तर्कों के साथ बुलाता है जब तक `n <= 1` नहीं हो जाता। यह इसलिए काम करता है क्योंकि `if ... then ... else ...` रूप केवल उसी शाखा की गणना करता है जिसकी ज़रूरत है।

> फ़ंक्शन का शरीर एक ही व्यंजक होता है, एक पंक्ति। कई गणनाएँ जोड़ने के लिए `;` से स्क्रिप्ट बनाएँ (अगला भाग)।

### 1.11 स्क्रिप्ट: एक साथ कई कथन

*स्क्रिप्ट* कई कथन होते हैं जो `;` से जुड़े होते हैं या नई पंक्तियों से, जिनका अर्थ बिल्कुल वही होता है, और एक के बाद एक चलते हैं:

```epher
x = 10; y = x + 5; x + y
```

```text
25
```

स्क्रिप्ट छोटे प्रोग्राम बनाने का तरीका है: चर तैयार करें, लूप चलाएँ, और अंतिम परिणाम दिखाएँ।

नई पंक्तियाँ और `;` एक ही विभाजक हैं, और आप उन्हें स्वतंत्र रूप से मिला सकते हैं। बहु-पंक्ति वाले उदाहरण के ऊपर **कॉपी करें** बटन पूरी स्क्रिप्ट कॉपी करता है, और आप उसे सीधे epher में चिपका सकते हैं: वेब ऐप और डेस्कटॉप ऐप का एंट्री फ़ील्ड, टर्मिनल इंटरफ़ेस और `epher repl`, ये सभी हर पंक्ति को क्रम से चलाते हैं, ठीक वैसे ही जैसे आपने उन्हें एक-एक करके टाइप किया हो। कई कथनों को `;` से एक पंक्ति में जोड़ना भी हर जगह काम करता है, एक-बार कमांड लाइन सहित (धारा 4.1)।

### 1.12 सटीक परिणाम: frac, dec और big

आम तौर पर epher पॉकेट कैलकुलेटर की तरह दशमलव संख्याओं से गणना करता है। कुछ संख्याएँ सटीक रूप में बेहतर दिखती हैं।

**frac(n, d)** एक सटीक भिन्न बनाता है:

```epher
1 / 3
```

```text
0.3333333333333333
```

```epher
frac(1, 3)
```

```text
1/3
```

भिन्न गणनाओं में सटीक बनी रहती हैं:

```epher
frac(1, 3) * 3
```

```text
1
```

**dec(x)** एक सटीक दशमलव बनाता है। इन दोनों की तुलना करें:

```epher
0.1 + 0.2
```

```text
0.30000000000000004
```

```epher
dec(0.1) + dec(0.2)
```

```text
0.3
```

पहला परिणाम वह छोटी पूर्णांकन त्रुटि है जो हर कंप्यूटर दशमलव संख्याओं से करता है। `dec()` इसे हटा देता है।

**big(x)** एक सटीक पूर्णांक बनाता है, उन मानों के लिए जो पॉकेट कैलकुलेटर की सीमा से बड़े हैं:

```epher
big(10 ^ 20)
```

```text
100000000000000000000
```

**संख्या आधार** पूर्णांकों को वैसे ही लिखते हैं जैसे गणित समुदाय लिखता है:
`0b` द्विआधारी के लिए, `0o` अष्टाधारी के लिए, `0x` षोडशाधारी के लिए
(उपसर्ग केवल वर्तनी बदलता है, मान कभी नहीं):

```epher
0b1010 + 0xFF
```

```text
265
```

**bin(x)**, **oct(x)** और **hex(x)** से वापस बदलें। ये एक पूर्ण संख्या की
उपसर्ग-सहित वर्तनी देते हैं, जिसे सीधे दोबारा इस्तेमाल किया जा सकता है:

```epher
hex(255)
bin(10)
```

```text
0xff
0b1010
```

### 1.13 अंतर्निर्मित फ़ंक्शन

epher में वैज्ञानिक कैलकुलेटर के फ़ंक्शन हैं, परिवार के अनुसार समूहबद्ध।

त्रिकोणमिति रेडियन में काम करती है। बदलने के लिए `deg` और `rad` का उपयोग करें:

| फ़ंक्शन | अर्थ | उदाहरण | परिणाम |
|---|---|---|---|
| `sin(x)`, `cos(x)`, `tan(x)` | त्रिकोणमितीय फ़ंक्शन | `sin(pi / 2)` | `1` |
| `asin(x)`, `acos(x)`, `atan(x)` | प्रतिलोम त्रिकोणमिति | `atan(1)` | `0.7853981633974483` |
| `atan2(y, x)` | बिंदु (x, y) का कोण | `atan2(1, 1)` | `0.7853981633974483` |
| `deg(x)` | रेडियन → डिग्री | `deg(pi)` | `180` |
| `rad(x)` | डिग्री → रेडियन | `rad(180)` | `3.141592653589793` |

### 1.16 खगोल और सौर मंडल

epher खगोल बोलता है: इकाई प्रत्यय, भौतिक स्थिरांक, कैलेंडर और समय के फलन,
और सूर्य, चंद्रमा, ग्रहों और प्लूटो के लिए सजीव ग्रहपत्रिका (एफेमेरिस)।
सब कुछ ऑफ़लाइन काम करता है।

**खगोल बोलने वाली इकाइयाँ।** संख्या के बाद इकाई प्रत्यय लिखें, और epher उसे
तुरंत SI इकाइयों में बदल देता है:

| प्रत्यय | इकाई | बदलता है |
|---|---|---|
| `AU` या `au` | खगोलीय इकाई | मीटर |
| `pc` | पारसेक | मीटर |
| `ly` | प्रकाश वर्ष | मीटर |
| `deg` | डिग्री | रेडियन |
| `arcmin`, `arcsec` | आर्कमिनट, आर्कसेकंड | रेडियन |
| `min`, `hr`, `d`, `yr` | मिनट, घंटा, दिन, जूलियन वर्ष | सेकंड |
| `Jy` | जांस्की | W m-2 Hz-1 |

```epher
3.2 AU
```

```text
478713186240
```

```epher
sin(30 deg)
```

```text
0.5
```

प्रत्यय व्याकरण का हिस्सा हैं: कोई भी उपयोगकर्ता स्थिरांक `3.2 AU` का अर्थ
नहीं बदल सकता, और `h` प्लांक स्थिरांक ही रहता है; घंटे `hr` लिखे जाते हैं।
फलन प्राकृतिक इकाइयों में गिनती लौटाते हैं; प्रत्यय गिनती को SI में बदलता
है, इसलिए `mag2jy(20)` जांस्की गिनती है और `mag2jy(20) Jy` वही फ्लक्स
वाट प्रति वर्ग मीटर हर्ट्ज़ में है।

**खगोलीय स्थिरांक।** `au`, `pc`, `ly`, `c`, `g`, `h`, `h_bar`, `k_b`,
`sigma_sb`, `m_sun`, `r_sun`, `l_sun`, `m_earth`, `r_earth` `pi` की तरह
काम करते हैं, और आप उन्हें अपने स्थिरांकों से छायांकित कर सकते हैं।

**तारीख़ और समय।** `jd(y, m, d [, hr])` और `mjd(...)` कैलेंडर तारीख़ को
जूलियन तिथि में बदलते हैं; `now()` वर्तमान क्षण पढ़ता है:

```epher
jd(2000, 1, 1, 12)
```

```text
2451545
```

`delta_t(jd)` TT - UT1 संशोधन है, और `lst(jd, lon)` देशांतर (डिग्री में,
पूर्व धनात्मक) के लिए स्थानीय नाक्षत्र समय है (घंटों में)।

**घंटे, मिनट और सेकंड।** `hms2deg(h, m, s)` विषुवत रेखांश को डिग्री में
बदलता है, `dms2deg(d, m, s)` षाष्ट्यंशीय कोण को, और `deg2hms(x)` /
`deg2dms(x)` कोण को पाठ के रूप में लिखते हैं:

```epher
deg2hms(90)
```

```text
6h 0m 0s
```

**आकाश, संख्याओं में।** हर एक्सेसर को एक पिंड संख्या दें: बुध 1, शुक्र 2,
मंगल 4, बृहस्पति 5, शनि 6, अरुण 7, वरुण 8, प्लूटो 9, सूर्य 10, चंद्रमा 11
(पृथ्वी 3 है, प्रेक्षक, कभी लक्ष्य नहीं)।

| फलन | अर्थ |
|---|---|
| `ra(b, jd)`, `decl(b, jd)` | भूकेंद्रित विषुवत रेखांश और क्रांतिवृत्तांश (डिग्री) |
| `dist(b, jd)` | दूरी (खगोलीय इकाइयों में) |
| `alt(b, jd, lat, lon)`, `az(b, jd, lat, lon)` | शीर्षकेंद्रित ऊँचाई और दिगंश (डिग्री, सत्य) |
| `rise(b, jd, lat, lon)`, `set(...)`, `transit(...)` | स्थानीय सौर दिन की घटनाएँ, जूलियन तिथियों के रूप में |
| `mag(b, jd)` | दृश्य कांतिमान |
| `phase(b, jd)`, `illum(b, jd)` | कला कोण (डिग्री) और प्रदीप्त भाग |
| `diam(b, jd)` | कोणीय व्यास (डिग्री) |

```epher
decl(10, jd(2000, 6, 21, 1.8))
```

```text
23.437882351
```

अक्षांश और देशांतर डिग्री में हैं, पूर्व धनात्मक। बिना प्रेक्षक के स्थिति
भूकेंद्रित होती है। प्लूटो लगभग एक आर्कमिनट तक ईमानदार निकट-कक्षा पर चलता
है, जो अन्य पिंडों की सटीकता से बहुत नीचे है; ग्रहण और युति खोज शामिल नहीं
हैं।

**प्रकाशिकी और प्रकाश।** `kepler(M, e)` केप्लर समीकरण हल करता है,
`airmass(alt)` sec(z) वायुमंडल है, `dawes(d)` d-मिलीमीटर द्वार की विभेदन
क्षमता है (आर्कसेकंड में), और `dist_mod(mu)` दूरी मापांक को पारसेक में
बदलता है।

**ऋतुएँ।** `march_equinox(year)`, `june_solstice(year)`,
`september_equinox(year)` और `december_solstice(year)` हर ऋतु सीमा की
जूलियन तिथि लौटाते हैं:

```epher
march_equinox(2000)
```

```text
2451623.8159797275
```

**3D में सौर मंडल।** `solar3d` कमांड पूरा सौर मंडल बनाता है: हर कक्षा एक
वक्र के रूप में, हर पिंड एक लेबल वाले बिंदु के रूप में, और साथ में एक रास्ता
जो दिखाता है कि वह अभी कहाँ था:

```epher
solar3d jd(2020, 7, 1)
```

समय को एक स्थिरांक के रूप में दें और ग्रहों को चलते देखने के लिए प्ले बटन
दबाएँ: `const t = jd(now()); solar3d t`। घुमाने के लिए खींचें या तीर
कुंजियाँ दबाएँ, `clear` से खाली करें, और `solar3d save file.svg` से निर्यात
करें।

ग्रहपत्रिका की गणना solar-ephemeris क्रेट (github.com/Protonmatter/sol)
करता है, जो JPL Horizons से सत्यापित है; इसके लेखक को धन्यवाद। वर्तमान के
आसपास लगभग 5000 वर्षों में सूर्य, चंद्रमा और ग्रहों के लिए सटीकता
आर्कसेकंड-श्रेणी की है।

## 2. वेब ऐप (PWA)

### 2.1 इसे खोलना

वेब ऐप इस पते पर है:

```text
https://epher.org/pwa/
```

किसी इंस्टॉलेशन की ज़रूरत नहीं। यह किसी भी आधुनिक ब्राउज़र में कंप्यूटर, फ़ोन या टैबलेट पर चलता है।

यह गाइड ऐप में भी बनी हुई है: मेनू बार में **Help → User guide** खोलें (फ़ोन पर **☰** टैप करें) और इसे ऐप के अंदर, ऐप की मौजूदा भाषा में पढ़ें। उस गाइड में किसी भी उदाहरण पर टैप करें। वह एंट्री फ़ील्ड में लोड हो जाता है।

### 2.2 आपकी पहली गणना

1. टेक्स्ट फ़ील्ड पर क्लिक करें (पेज लोड होते ही उसमें फ़ोकस होता है)।
2. एक व्यंजक टाइप करें, जैसे `2 + 3 * 4`।
3. **Enter** दबाएँ या **=** बटन पर क्लिक करें।

परिणाम फ़ील्ड के नीचे बड़े अक्षरों में दिखाई देता है। अध्याय 1 की हर चीज़ यहाँ काम करती है, जिसमें चर, फ़ंक्शन और स्क्रिप्ट शामिल हैं।

### 2.3 इतिहास

हर गणना परिणाम के नीचे इतिहास सूची में जुड़ती है, ताकि आप पीछे देख सकें कि आपने क्या किया। नई प्रविष्टियाँ सबसे ऊपर दिखाई देती हैं, और सूची के ऊपर **Clear history** बटन इसे खाली कर देता है। इतिहास तब तक रहता है जब तक पेज खुला है।

हर मद पतली रेखाओं के बीच बैठता है: एक-पंक्ति का व्यंजक एक कतार है, और बहु-पंक्ति की स्क्रिप्ट एक मद है जो अपनी सभी पंक्तियाँ दिखाता है। किसी मद पर क्लिक करके उसे वापस इनपुट फ़ील्ड में लाएँ और फिर से चलाएँ।

### 2.4 ग्राफ़िंग

`graph` टाइप करें और फिर एक व्यंजक, और **Enter** दबाएँ:

```epher
graph x ^ 2
```

epher वक्र y = f(x) को x = −10 से x = 10 तक लेबल वाले अक्षों वाले ग्रिड पर, इनपुट के नीचे खींचता है। आप किसी भी व्यंजक का ग्राफ़ बना सकते हैं, जिसमें आपके अपने फ़ंक्शन शामिल हैं:

```epher
def f(x) = x ^ 3
graph f(x)
```

हर `graph` पंक्ति उसी प्लॉट में एक और वक्र जोड़ती है, हर वक्र का अपना रंग होता है। सभी वक्र ठोस होते हैं, और लीजेंड तथा
कैप्शन ही उन्हें बिना रंग के अलग पहचानते हैं। `graph clear` प्लॉट खाली करता है, और ग्राफ़ पेन के ऊपर **Clear graph** बटन वक्रों और 3D सतहों के लिए एक साथ यही करता है। TUI इस कमांड को अपने **Graph** मेनू में रखता है।

ग्राफ़ पैन के ऊपरी भाग में, **Clear graph** और **Copy SVG** के बगल
में, टूलबार से आप रुचि के बिंदुओं की सूची और ग्राफ़ पर दिखाए गए उजागर
बिंदु छिपा सकते हैं। **रेखा की मोटाई** स्लाइडर **Copy SVG** के दाईं
ओर होता है (फ़ोन पर उसकी अपनी पंक्ति में, नीचे): 2D वक्रों के लिए 0 से 4
तक 0.1 के चरणों वाला स्लाइडर, 3D सतहों के लिए 0 से 0.2 तक 0.01 के
चरणों वाला दूसरा स्लाइडर, दिखता केवल वर्तमान प्रकार का स्लाइडर है, और
हर प्रकार अपना मान याद रखता है। लीजेंड की हर प्रविष्टि के सामने एक
चेकबॉक्स है, डिफ़ॉल्ट रूप से चेक किया हुआ: उसे खाली करने पर वह वक्र
प्लॉट, उसके रुचि बिंदुओं और SVG निर्यात से छिप जाता है।

```epher
graph x ^ 2
graph x ^ 3
```

जिन बिंदुओं पर व्यंजक का कोई मान नहीं है (जैसे शून्य से भाग) उन्हें छोड़ दिया जाता है, जिससे वक्र में खाली जगह रह जाती है। जो उछाल वास्तव में एक लंबवत अनंतस्पर्शी रेखा है उसे कभी जोड़ने वाली रेखा के रूप में नहीं खींचा जाता।

#### 2.4.1 आप क्या प्लॉट कर सकते हैं

अपनी पसंद का प्रांत:

```epher
graph sin(x) from 0 to 2*pi
```

पैरामीट्रिक वक्र (t 0 से 2π तक चलता है):

```epher
graph param 2*cos(t), 3*sin(t)
```

ध्रुवीय वक्र:

```epher
graph polar 1 + cos(theta)
```

क्षेत्र: `y <` वक्र के नीचे का क्षेत्र भरता है, `y >` ऊपर का भरता है:

```epher
graph y < x ^ 2
```
#### 2.4.2 प्लॉट पढ़ना

**ट्रेस:** पॉइंटर को प्लॉट पर ले जाएँ, या उस पर फ़ोकस करें और तीर कुंजियाँ दबाएँ। वक्र का सबसे नज़दीकी बिंदु चिह्नित हो जाता है, उसके निर्देशांक प्लॉट के नीचे दिखाए जाते हैं।

**रुचि के बिंदु:** हर graph कमांड के बाद epher हर वक्र के मूल और मोड़ बिंदु तथा वक्रों के बीच प्रतिच्छेदन ढूँढता है, उन्हें प्लॉट पर चिह्नित करता है, और उन्हें उसके नीचे सूचीबद्ध करता है:

```text
root (-1, 0)   minimum (0, 0)   root (1, 0)
```

**सारणियाँ:** `table` कमांड मानों की सारणी छापता है (जिन पंक्तियों में व्यंजक का कोई मान नहीं है वे खाली रहती हैं):

```epher
table x ^ 2 from -2 to 2 points 5
```

```text
         x           y
        -2           4
        -1           1
         0           0
         1           1
         2           4
```

#### 2.4.3 स्लाइडर और निर्यात

एक स्थिरांक परिभाषित करें और उसे ग्राफ़ में उपयोग करें, और प्लॉट के नीचे एक स्लाइडर दिखाई देता है। उसे खींचें (या तीर कुंजियों से हिलाएँ) और हर वक्र फिर से खिंच जाता है:

```epher
const a = 1
graph a * x ^ 2
```

**Copy SVG** मौजूदा प्लॉट को स्वसंपूर्ण SVG छवि के रूप में कॉपी करता है,
दस्तावेज़ों में चिपकाने के लिए। रंग अंदर ही बसे हैं, इसलिए वह हर जगह
एक जैसा दिखता है। स्लाइडर पंक्तियाँ और एनिमेटेड स्थिरांक प्लॉट के
ठीक नीचे, रुचि बिंदुओं की सूची के ऊपर बैठते हैं।

#### 2.4.4 3D सतहें

`graph3d` एक वर्गाकार प्रांत (−5 से 5, या आपका `from a to b`) पर सतह z = f(x, y) प्लॉट करता है:

```epher
graph3d x ^ 2 - y ^ 2
```

आपके नज़दीक की मेश रेखाएँ ज़्यादा गहरी खींची जाती हैं, इसलिए आकृति में गहराई दिखाई देती है। कई `graph3d` पंक्तियाँ वक्रों की तरह एक के ऊपर एक खिंचती हैं, और `graph3d clear` प्लॉट खाली करता है। खींचकर दृश्य घुमाएँ, या प्लॉट पर फ़ोकस करें और तीर कुंजियाँ इस्तेमाल करें। टर्मिनल इंटरफ़ेस उसी सतह को ASCII वायरफ़्रेम के रूप में खींचता है, जिसे तीर कुंजियाँ घुमाती हैं।

#### 2.4.5 एनिमेशन

हर स्लाइडर में एक प्ले बटन होता है। वह अपने स्थिरांक को स्लाइडर की सीमा में कदम-दर-कदम चलाता है और फिर वापस शुरुआत में घूम जाता है। यह कैलकुलेटरों का एनिमेट करने का मानक तरीका है: आप एक पैरामीटर एनिमेट करते हैं, और उसका इस्तेमाल करने वाली हर चीज़ हिलती है। रोकने के लिए बटन दोबारा दबाएँ।

एक "समय" चर बस एक स्थिरांक है जिसे आप एनिमेट करते हैं:

```epher
const t = 0
graph sin(x - t)
```

t का स्लाइडर चलाने से तरंग आगे बढ़ती है। 3D सतहें भी इसी तरह एनिमेट होती हैं। पहले एक स्थिरांक परिभाषित करें, फिर उसका स्लाइडर चलाएँ:

```epher
const a = 1
graph3d sin(a * (x ^ 2 + y ^ 2)) from -3 to 3
```

टर्मिनल इंटरफ़ेस में, स्पेस बार एनिमेशन शुरू और बंद करता है।

### 2.5 इसे इंस्टॉल करना और ऑफ़लाइन उपयोग

वेब ऐप एक *प्रगतिशील वेब ऐप* है: एक बार देखने के बाद यह पूरी तरह ऑफ़लाइन काम करता है, और आप इसे सामान्य ऐप की तरह इंस्टॉल कर सकते हैं।

- **Chrome, Edge या Android:** एड्रेस बार में इंस्टॉल आइकन पर क्लिक करें (या ब्राउज़र मेनू में *Install app*), फिर पुष्टि करें।
- **iPhone / iPad (Safari):** **Share** → **Add to Home Screen** पर टैप करें।
- **अन्य ब्राउज़र:** मेनू में *Install* या *Add to Home Screen* देखें।

एक बार इंस्टॉल होने पर, इसे होम स्क्रीन या ऐप सूची से खोलें। यह बिना इंटरनेट कनेक्शन के भी तुरंत खुलता है।

### 2.6 वेब ऐप क्या नहीं करता

वेब ऐप आपके काम को मौजूदा सत्र तक रखता है: यह व्यंजकों का मूल्यांकन करता है, उनका ग्राफ़ बनाता है (धारा 2.4), और इतिहास रखता है। **save**, **save script** और **language** कमांड डेस्कटॉप, कमांड लाइन और टर्मिनल संस्करणों में काम करते हैं (अध्याय 3, 4 और 5)। वेब ऐप में वे एक नोट के साथ उत्तर देते हैं कि सहेजना वहाँ काम करता है। इतिहास दो विज़िट के बीच सहेजा नहीं जाता।

## 3. डेस्कटॉप ऐप

डेस्कटॉप ऐप उसी वेब ऐप के चारों ओर एक सामान्य विंडो है। अध्याय 2 की हर बात लागू होती है; फ़र्क केवल इंस्टॉल और शुरू करने के तरीके में है।

### 3.1 इंस्टॉल करना

epher वेबसाइट से अपने सिस्टम के लिए एक इंस्टॉलर डाउनलोड करें:

- **Windows:** `epher-windows-x86_64.exe` चलाएँ। इंस्टॉलर `epher` को आपके PATH पर रखता है। नई CMD या PowerShell विंडो खोलें और `epher "2 + 2"` चल जाता है। चूँकि बिल्ड हस्ताक्षरित नहीं है, पहली बार *More info* → *Run anyway* चुनें।
- **macOS:** `epher-macos-aarch64.dmg` खोलें और epher को Applications में खींचें। चूँकि बिल्ड हस्ताक्षरित नहीं है, पहली बार खोलने के लिए राइट-क्लिक → **Open** करें।
- **Linux (Debian/Ubuntu):** `.deb` पैकेज

```sh
sudo apt install ./epher-linux-x86_64.deb
```

- **Linux (Fedora/RHEL):** `.rpm` पैकेज

```sh
sudo dnf install ./epher-linux-x86_64.rpm
```

- **Linux (कोई भी डिस्ट्रो, Arch सहित):** AppImage। इसे चलाने योग्य बनाएँ और चलाएँ:

```sh
chmod +x epher-linux-x86_64.AppImage
./epher-linux-x86_64.AppImage
```

हर इंस्टॉलर में *पूरा* epher होता है: डेस्कटॉप ऐप, कमांड लाइन (अध्याय 4) और टर्मिनल इंटरफ़ेस (अध्याय 5), सब एक ही `epher` कमांड के रूप में। Linux पर, पैकेज `epher` को `/usr/bin` में रखता है।

### 3.2 उपयोग

epher को किसी भी अन्य एप्लिकेशन की तरह शुरू करें। आपको वेब ऐप जैसा ही इंटरफ़ेस वाली विंडो मिलती है: व्यंजक टाइप करें, **Enter** दबाएँ या **=** पर क्लिक करें, और परिणाम पढ़ें। ग्राफ़िंग यहाँ भी काम करती है। `graph x ^ 2` विंडो में खींचता है (अध्याय 2.4)। विंडो का आकार स्वतंत्र रूप से बदला जा सकता है। मेनू बार में **Help → User guide** शामिल है, इस पेज जैसी ही गाइड, जिसके उदाहरण टैप करने पर लोड होते हैं।

इसे टर्मिनल से भी खोल सकते हैं: बिना तर्क वाला `epher` (या `epher gui`) डेस्कटॉप ऐप शुरू करता है। macOS पर, ऐप के अंदर **Install the epher command** बटन से `epher` आपके टर्मिनल PATH पर आ जाता है।

### 3.3 भंडारण: CLI और TUI के साथ एक ही स्टोर

डेस्कटॉप ऐप अपना भंडारण कमांड लाइन और टर्मिनल संस्करणों के साथ साझा करता है। फ़ंक्शन, स्थिरांक, स्क्रिप्ट, इतिहास और भाषा पसंद एक ही जगह रहते हैं, आपके कंप्यूटर पर `~/.epher` (या `EPHER_STORE_DIR`, अध्याय 4.6), और एक संस्करण में सहेजी गई हर चीज़ दूसरों में उपलब्ध है:

```text
def area(w, h) = w * h
save area
```

`area` को डेस्कटॉप ऐप में परिभाषित करें, `save` करें, विंडो बंद करें। फिर CLI खोलें और `area(3, 4)` बस काम करता है। उल्टा भी यही है: डेस्कटॉप विंडो खुलने पर CLI या TUI में सहेजे गए फ़ंक्शन और स्क्रिप्ट पहले से वहाँ होते हैं, सहेजी गई स्क्रिप्टों द्वारा सेट किए गए चर सहित। अध्याय 4 के `save`, `save script` और `language` कमांड यहाँ बिल्कुल उसी तरह काम करते हैं।

CLI, REPL, TUI या डेस्कटॉप ऐप में टाइप किए गए कमांड सभी एक ही इतिहास में जुड़ते हैं, और सत्र भी साथ चलता है: आपके द्वारा निर्धारित चर और `ans` मान एक संस्करण से दूसरे में आपका पीछा करते हैं। साझा स्टोर लाइव है: जब दो संस्करण एक साथ खुले हों, तो एक में बदलाव तुरंत दूसरे में दिखाई देता है (डेस्कटॉप ऐप और TUI स्टोर देखते हैं और अपने आप ताज़ा होते हैं)।

> ब्राउज़र में वेब ऐप ही एकमात्र संस्करण है जो इस स्टोर का उपयोग नहीं करता। हर सत्र अलग रहता है (अध्याय 2.6)।

## 4. कमांड लाइन (CLI)

CLI उसी `epher` प्रोग्राम का टेक्स्ट रूप है जो डेस्कटॉप ऐप है। इसके तीन मोड हैं: एक-बार मूल्यांकन, पाइप्ड स्क्रिप्ट, और लंबे काम के लिए इंटरैक्टिव सत्र।

किसी भी समय सहायता के लिए `epher --help` चलाएँ (सभी कमांड, उदाहरणों के साथ)
या `epher help` (पूरा मैनुअल; Linux पैकेजों पर यह `man epher` मैनुअल पेज है)।

### 4.1 एक-बार गणनाएँ

व्यंजक को तर्क के रूप में दें:

```sh
epher "2 + 3 * 4"
```

```text
14
```

अध्याय 1 की कोई भी एकल व्यंजक वाली चीज़:

```sh
epher "if 3 > 2 then 10 else 20"
```

```text
10
```

ऋण चिह्न से शुरू होने वाला व्यंजक सीधे चलता है:

```sh
epher "-2 + 5"
```

```text
3
```

एक-बार मोड स्क्रिप्ट के लिए है, एक व्यंजक से लेकर पूरे प्रोग्राम तक। हर कथन का मान अपनी पंक्ति में छपता है:

```sh
epher "x = 10; x + 5"
```

```text
10
15
```

नई पंक्तियों से जुड़े कथन तर्क के अंदर उसी तरह काम करते हैं। अध्याय 1 की हर चीज़ उपलब्ध है: चर, फ़ंक्शन, लूप, सब कुछ। पंक्तियाँ एक ही सत्र साझा करती हैं, पाइप्ड स्क्रिप्ट की तरह (अनुभाग 4.2)।

### 4.2 पाइप्ड स्क्रिप्ट

`epher -` मानक इनपुट से एक-एक पंक्ति व्यंजक पढ़ता है, जैसे पाइपलाइनों में स्क्रिप्टिंग भाषाएँ चलती हैं:

```sh
printf "x = 3\nx * 10\n" | epher -
```

```text
= 3
= 30
```

अध्याय 1 की हर चीज़ काम करती है, और पंक्तियाँ एक ही सत्र साझा करती हैं: पहले परिभाषित फ़ंक्शन बाद में उपलब्ध है, और `save` हमेशा की तरह उसी स्टोर में लिखता है। त्रुटियाँ छपती हैं और स्क्रिप्ट चलती रहती है। एक पंक्ति कई कथनों को `;` से जोड़ सकती है। नई पंक्तियों और `;` का अर्थ epher में हर जगह एक जैसा है।

### 4.3 इंटरैक्टिव सत्र (REPL)

इसे `epher repl` से शुरू करें:

```sh
epher repl
```

> बिना तर्क वाला `epher` डेस्कटॉप ऐप खोलता है (अध्याय 3)।

epher अपना प्रॉम्प्ट दिखाता है और इंतज़ार करता है:

```text
epher>
```

अब अध्याय 1 की कोई भी चीज़ एक-एक पंक्ति में टाइप करें। चर अपना मान पंक्तियों के बीच रखते हैं:

```text
epher> x = 5
= 5
epher> x ^ 2
= 25
```

`table` कमांड (धारा 2.4.2) यहाँ भी मानों की सारणी छापता है:

```text
epher> table x ^ 2 from -2 to 2 points 5
         x           y
        -2           4
        -1           1
         0           0
        `graph` पंक्तियाँ यहाँ भी चलती हैं: वक्र पंक्तियों के साथ जुड़ते जाते हैं,
और `graph save plot.svg` वही SVG छवि लिखता है जो वेब ऐप का **Copy SVG**
बटन देता है। `graph3d save file.svg` उसी तरह 3D सतह सहेजता है। ये ही
पंक्तियाँ एक-बार के मूल्यांकन और पाइप की गई स्क्रिप्ट में भी चलती हैं:
`epher "graph sin(x); graph save plot.svg"` एक ही कमांड में पूरा प्लॉट है।

 1           1
         2           4
```

हर उत्तर `= परिणाम` के रूप में दिखता है। बाहर निकलने के लिए `quit` (या `exit`) टाइप करें:

```text
epher> quit
```

आपका इतिहास याद रखा जाता है: अगली बार `epher repl` चलाने पर पिछले सत्र की पंक्तियाँ अब भी मौजूद रहती हैं।

### 4.4 फ़ंक्शन, स्थिरांक और स्क्रिप्ट सहेजना

एक फ़ंक्शन परिभाषित करें, फिर सहेजें:

```text
epher> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
epher> save fib
saved fib
```

`save fib` कमांड फ़ंक्शन को डिस्क पर संग्रहीत करता है। अगली बार सत्र शुरू करने पर `fib` पहले से परिभाषित होता है:

```text
epher> fib(10)
= 55
```

स्थिरांक उसी तरह सहेजे जाते हैं। स्थिरांक के नाम पर `save`:

```text
epher> const tax = 0.2
= 0.2
epher> save tax
saved tax
```

पूरी स्क्रिप्ट (आपकी आखिरी टाइप की गई पंक्ति) सहेजने के लिए `save script` उपयोग करें:

```text
epher> x = 0; while x < 5 do x = x + 1; x
= 5
epher> save script count_to_five
saved script count_to_five
```

सहेजी गई स्क्रिप्ट epher शुरू होने पर स्वतः चलती हैं, इसलिए उनमें परिभाषित सब कुछ आपके लिए तैयार रहता है।

### 4.5 इंटरफ़ेस भाषा बदलना

इंटरफ़ेस भाषा आपके डिवाइस पर सेट भाषाओं से चुनी जाती है। इसे बदलने के लिए `language` टाइप करें और फिर इनमें से एक: `en`, `zh-CN`, `hi`, `es`, `fr`, `ar`, `de`, `pt`:

```text
epher> language fr
language set to fr
```

चुनाव अगली बार के लिए याद रखा जाता है। ध्यान दें: जो भाषा आप *टाइप* करते हैं, व्यंजकों की भाषा, हमेशा एक जैसी रहती है, किसी भी इंटरफ़ेस भाषा में।

### 4.6 आपका डेटा कहाँ रहता है

फ़ंक्शन, स्क्रिप्ट, इतिहास और आपकी भाषा का चुनाव आपके कंप्यूटर के एक फ़ोल्डर में संग्रहीत होते हैं:

```text
~/.epher
```

पूरी तरह नई शुरुआत के लिए उस फ़ोल्डर को हटा दें। दूसरा स्थान उपयोग करने के लिए, epher शुरू करने से पहले `EPHER_STORE_DIR` पर्यावरण चर सेट करें:

```sh
EPHER_STORE_DIR=/tmp/my-epher epher repl
```

## 5. टर्मिनल इंटरफ़ेस (TUI)

TUI इंटरैक्टिव सत्र का फुल-स्क्रीन संस्करण है, जो आपके टर्मिनल के अंदर चलता है। यह उसी `epher` प्रोग्राम का हिस्सा है। इसे शुरू करें:

```sh
epher tui
```

### 5.1 स्क्रीन

स्क्रीन पैनलों में विभाजित है:

- **व्यंजक**: इनपुट बॉक्स (ऊपर)। Shift+Enter नई पंक्ति शुरू करता है;
  तीर कुंजियाँ या माउस क्लिक पाठ में कर्सर घुमाते हैं।
- उसके ठीक नीचे वर्तमान **परिणाम**।
- **इतिहास**: आपकी हर पंक्ति, उत्तर सहित।
- **ग्राफ़**: `graph` कमांड का प्लॉट (नीचे)।
- एक संकेत पंक्ति कीबोर्ड शॉर्टकट दिखाती है।

### 5.2 कुंजियाँ

| कुंजी | क्रिया |
|---|---|
| टाइप करें | कर्सर पर व्यंजक में जोड़ें |
| **Enter** | पूरी स्क्रिप्ट का मूल्यांकन करें (बहु-पंक्ति इनपुट एक इतिहास मद के रूप में चलता है) |
| **Shift+Enter** | नई पंक्ति शुरू करें |
| **← → ↑ ↓** | कर्सर घुमाएँ (खाली इनपुट पर: 3D दृश्य घुमाएँ) |
| **Esc** | इनपुट पंक्ति साफ़ करें |
| **Ctrl+C** | बाहर निकलें |
| **q** | बाहर निकलें (इनपुट खाली होने पर) |
| **Arrow keys** | 3D दृश्य घुमाएँ (इनपुट खाली होने पर) |
| **Space** | एनिमेशन शुरू/बंद करें (इनपुट खाली होने पर) |
| **F10** | मेनू खोलें (फ़ाइल, संपादन, ग्राफ़, सेटिंग्स, सहायता) |
| **Tab** | हमेशा दिखने वाले कीपैड पर फ़ोकस करें (या कीपैड से इतिहास पर); बैंक बदलें (**Esc** टाइपिंग पर लौटाता है) |
| **माउस** | मेनू और मेनू आइटम पर क्लिक करें, कीपैड सेल और बैंक टैब, इतिहास पंक्तियाँ (व्यंजक लोड करती हैं); ग्राफ़ पैनल खींचकर घुमाएँ (3D) या सरकाएँ (2D), व्हील ज़ूम करता है, डबल-क्लिक दृश्य रीसेट करता है |
| **Ctrl+L** | इतिहास साफ़ करें |

कीपैड के बैंक भाषा की हर फ़ंक्शन, स्थिरांक और कमांड रखते हैं: **trig**, **fn**, **num**, **0x** और **var**। 0x बैंक में सटीक और आधार रूपांतरण (`frac`, `dec`, `big`, `bin`, `oct`, `hex`) तथा फ़ैक्टोरियल `!` हैं। तीर कुंजियाँ चयन घुमाती हैं, **Enter** टोकन जोड़ता है, और **Tab** बैंक बदलता है।

### 5.3 ग्राफ़िंग

`graph` टाइप करें और फिर एक व्यंजक, और **Enter** दबाएँ:

```epher
graph x ^ 2
```

epher वक्र को x = −10 से x = 10 तक नमूना करता है और Graph पैनल में ASCII प्लॉट के रूप में खींचता है; प्लॉट के ऊपर का लीजेंड बताता है कि क्या प्लॉट हुआ है।

`graph clear` प्लॉट खाली करता है, और **Graph** मेनू भी यही करता है; **Help** मेनू इस गाइड को TUI के अंदर खोलता है (तीर कुंजियाँ स्क्रॉल करती हैं, **Esc** बंद करता है)। **Settings** मेनू
प्लॉट के नीचे सूचीबद्ध रुचि के बिंदु छिपा सकता है।

आप किसी भी व्यंजक का ग्राफ़ बना सकते हैं, जिसमें आपके अपने फ़ंक्शन शामिल हैं। पहले एक परिभाषित करें, फिर ग्राफ़ करें:

```epher
def f(x) = x ^ 3
graph f(x)
```

हर `graph` पंक्ति प्लॉट में एक वक्र जोड़ती है, जो अपने प्रतीक (`o`, `x`, `+`, `*`) से खींचा जाता है; `graph clear` प्लॉट खाली करता है। वेब ऐप वाला व्याकरण यहाँ भी लागू होता है: प्रांत (`graph sin(x) from 0 to 2*pi`), पैरामीट्रिक वक्र (`graph param 2*cos(t), 3*sin(t)`), ध्रुवीय वक्र (`graph polar 1 + cos(theta)`), और क्षेत्र (`graph y < x ^ 2` वक्र के नीचे का क्षेत्र भरता है)।

जिन बिंदुओं पर व्यंजक का कोई मान नहीं है (जैसे शून्य से भाग) उन्हें बस छोड़ दिया जाता है, जिससे प्लॉट में खाली जगह रह जाती है। हर graph कमांड के बाद TUI प्लॉट के नीचे रुचि के बिंदुओं (मूल, मोड़ बिंदु और प्रतिच्छेदन) की सूची देता है। `table` कमांड (धारा 2.4.2) यहाँ भी काम करता है।

`graph3d x ^ 2 - y ^ 2` 3D सतह को ASCII वायरफ़्रेम के रूप में प्लॉट करता है। इनपुट खाली रहने पर इसे तीर कुंजियों से घुमाएँ, और किसी स्लाइडर स्थिरांक को एनिमेट करने के लिए स्पेस बार दबाएँ (धारा 2.4.5)। नीचे की संकेत पंक्ति तीर और स्पेस के संकेत केवल तब दिखाती है जब कोई 3D सतह या एनिमेट करने योग्य वक्र प्रदर्शित हो।

`graph save plot.svg` मौजूदा प्लॉट को वही SVG छवि लिखता है जो वेब ऐप का
**Copy SVG** बटन देता है; `graph3d save file.svg` 3D वायरफ़्रेम को उसी
कोण से सहेजता है जिससे आप उसे देख रहे हैं।

### 5.4 सहेजना और स्थायित्व

TUI अपना संग्रहण CLI के साथ साझा करता है: एक में सहेजा गया सब कुछ दूसरे में उपलब्ध है। फ़ंक्शन, स्क्रिप्ट, इतिहास और भाषा पसंद `~/.epher` (अध्याय 4.6) में रहते हैं, और वही `save`, `save script` और `language` कमांड यहाँ काम करते हैं।

## 6. आपका डेटा और गोपनीयता

- **इंस्टॉल किया गया epher प्रोग्राम** (डेस्कटॉप ऐप, CLI और TUI) फ़ंक्शन, स्क्रिप्ट, इतिहास और भाषा चुनाव को `~/.epher` (या `EPHER_STORE_DIR`) में स्थानीय रूप से संग्रहीत करता है। कुछ भी आपके कंप्यूटर से बाहर नहीं जाता।
- **वेब ऐप** डिस्क पर कुछ नहीं रखता: इतिहास केवल पेज खुले रहने तक चलता है। वेब ऐप ऑफ़लाइन चल सकता है क्योंकि पेज को आपका ब्राउज़र स्वयं संग्रहीत करता है।

पाँचों संस्करण गणना पूरी तरह आपके डिवाइस पर करते हैं। कुछ भी कहीं नहीं भेजा जाता।
