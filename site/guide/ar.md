# دليل مستخدم epher

مرحباً! epher آلة حاسبة قابلة للبرمجة والكتابة النصية. يمكنك استخدامها لحساب سريع، أو لبناء دوالك وبرامجك الصغيرة. كل شيء متاح بثماني لغات.

هذا الدليل موجَّه للمبتدئين تماماً. يبدأ بأبسط حساب ممكن ثم يتدرج حتى القوة الكاملة للغة. كل مثال يبيّن ما تكتبه وما يجيبه epher.

هناك خمس طرق لاستخدام epher. اختر ما يناسبك:

| الإصدار | ما هو | متى تختاره |
|---|---|---|
| **سطر الأوامر** (CLI) | أوامر نصية في الطرفية | تعيش في الطرفية وتحب النصوص البرمجية |
| **REPL** | جلسة `epher` تفاعلية عند الموجه `epher>` | تريد تبادلاً سريعاً دون مغادرة الطرفية |
| **واجهة الطرفية** (TUI) | برنامج بملء الشاشة داخل الطرفية | تريد تطبيق طرفية برسوم بيانية وسجل على الشاشة |
| **تطبيق سطح المكتب** | برنامج مكتبي عادي بنافذته الخاصة | تريد تطبيقاً عادياً |
| **تطبيق الويب** (PWA) | يعمل في متصفحك، قابل للتثبيت، ويعمل دون اتصال | تريد أسرع بداية؛ دون تثبيت |

تطبيق سطح المكتب وسطر الأوامر وREPL وواجهة الطرفية برنامج واحد: تنزيل واحد يثبِّت أمر `epher` الذي يفعل الأربعة. تطبيق الويب هو الاستثناء: لا يحتاج أي تنزيل.

جميع الإصدارات الخمسة تفهم اللغة نفسها تماماً. تعلّمها مرة واحدة، واستخدمها في أي مكان.

## 1. لغة epher

يعلم هذا الفصل اللغة المشتركة بين جميع إصدارات epher. في تطبيق الويب أو تطبيق سطح المكتب، اكتب تعبيراً واضغط **Enter** (أو انقر زر **=**). في CLI، ابدأ الجلسة بـ `epher repl` واكتب بعد الموجه `epher>`. في TUI (`epher tui`)، اكتب فقط واضغط **Enter**. في CLI يمكنك أيضاً كتابة `epher "تعبير"` لتقييم تعبير واحد مباشرة.

### 1.1 أول عملية حساب لك

اكتب هذا:

```epher
2 + 3 * 4
```

يجيب epher:

```text
14
```

الضرب يتم قبل الجمع، تماماً كما في الرياضيات. تسمى هذه القاعدة *أسبقية العوامل*.

### 1.2 ترتيب العمليات

ترتيب الأسبقية الكامل، من الأقوى إلى الأضعف:

1. `!` المضروب و`%` النسبة المئوية (كلاهما لاحق)
2. `^` الأس
3. `*` و`/` الضرب والقسمة
4. `+` و`-` الجمع والطرح

استخدم الأقواس لتغيير الترتيب:

```epher
(2 + 3) * 4
```

```text
20
```

يحسب العامل `^` الأسس ويعمل من اليمين إلى اليسار:

```epher
2 ^ 10
```

```text
1024
```

```epher
2 ^ 3 ^ 2
```

```text
512
```

(`2 ^ 3 ^ 2` تعني `2 ^ (3 ^ 2)`، أي `2 ^ 9` = 512.)

يمكن أن يكون الأس كسراً. `2 ^ 0.5` هو الجذر التربيعي للعدد 2:

```epher
2 ^ 0.5
```

```text
1.4142135623730951
```

الطرح والقسمة يعملان من اليسار إلى اليمين:

```epher
10 - 3 - 2
```

```text
5
```

علامة `%` عامل لاحق يعني "مقسوماً على 100": `5%` تساوي 0.05. ولا ينظر أبداً إلى العوامل من حوله، لذا `200 + 10%` تساوي 200.1. ولزيادة 200 بنسبة 10%، اكتب الضرب:

```epher
200 * (1 + 10%)
```

```text
220
```

### 1.4 المقارنة والمنطق

يمكنك مقارنة الأرقام. النتيجة `true` (صحيح) أو `false` (خطأ):

| المقارنة | المعنى |
|---|---|
| `a > b` | a أكبر من b |
| `a < b` | a أصغر من b |
| `a >= b` | a أكبر من أو يساوي b |
| `a <= b` | a أصغر من أو يساوي b |
| `a == b` | a يساوي b (لاحظ الـ `=` المزدوج) |
| `a != b` | a لا يساوي b |

```epher
3 > 2
```

```text
true
```

```epher
1 != 2
```

```text
true
```

اجمع المقارنات بـ `and` و`or` و`not`:

```epher
3 > 2 and 2 < 3
```

```text
true
```

```epher
not 3 > 2
```

```text
false
```

### 1.5 المتغيرات

أعطِ اسماً لقيمة باستخدام `=` واحد:

```epher
x = 5
```

```text
5
```

يعيد epher إليك القيمة. من الآن فصاعداً يمكن استخدام `x` في أي مكان:

```epher
x ^ 2
```

```text
25
```

يمكنك تغيير متغير متى شئت. يحتفظ بقيمته حتى تغيّره:

```epher
x = x + 1
```

```text
6
```

> يمكن أن تحتوي الأسماء على حروف وشرطات سفلية، مثل `radius` أو `my_total`. لا يمكن أن تحتوي على مسافات ولا أن تبدأ برقم.

يحمل المتغير الخاص `ans` دائمًا الإجابة السابقة، مثل مفتاح `Ans` في
الآلة الحاسبة الجيبية، مفيد للحسابات المتسلسلة:

```epher
2 + 3
ans * 2
```

```text
5
10
```

### 1.6 الثوابت: أسماء لا تتغير أبدًا

*الثابت* اسم لا تتغير قيمته أبدًا، مثل `pi` المدمج، لكن باختيارك. عرّفه
بـ `const`:

```epher
const tax = 0.2
```

```text
0.2
```

استخدمه في أي مكان يصح فيه رقم:

```epher
100 * (1 + tax)
```

```text
120
```

القيمة ثابتة: تغييرها بـ `=` خطأ،

```epher
tax = 0.25
```

```text
error: cannot assign to constant tax
```

وتعريف الثابت نفسه بقيمة مختلفة كذلك:

```epher
const tax = 0.25
```

```text
error: constant already defined: tax
```

تختلف الثوابت عن المتغيرات في نقطة أخرى: مثل `pi`، تعمل داخل دوالك
الخاصة.

```epher
const g = 9.81
```

```text
9.81
```

```epher
def weight(m) = m * g
```

```epher
weight(80)
```

```text
784.8000000000001
```

احفظ ثابتًا للجلسات القادمة بـ `save tax`، تمامًا كدالة (الفصل 4.4).

> لا يمكن أن يتشارك متغير وثابت الاسم نفسه: بعد `const tax = 0.2`، يظل
> `tax = ...` خطأً دائمًا. اختر اسمًا جديدًا أو ابدأ جلسة جديدة.

### 1.7 اتخاذ القرارات بـ if

`if` يختار بين قيمتين:

```epher
if 3 > 2 then 10 else 20
```

```text
10
```

الصيغة دائماً `if شرط then القيمة_عند_الصحة else القيمة_عند_الخطأ`. الجزء `else` إلزامي.

مثال أكثر فائدة مع متغير:

```epher
price = 100
if price > 50 then 2 else 1
```

```text
2
```

> لا يحتوي epher على قيم نصية: يجب أن يكون فرعا `if` رقمين (أو نتيجتي مقارنات).

### 1.8 الحلقات بـ while

يكرر `while` عبارة ما ما دام الشرط محققاً:

```epher
x = 0; while x < 5 do x = x + 1; x
```

```text
5
```

اقرأ هذا النص البرمجي هكذا: *ابدأ x عند 0؛ ما دام x أصغر من 5، أضف 1 إلى x؛ ثم اعرض x.* النتيجة 5 لأن الحلقة دارت خمس مرات.

> **شبكة أمان:** يوقف epher أي حلقة بعد 100 000 خطوة ويعرض `error: step limit exceeded`. هذا يحميك من الحلقات التي لا تنتهي أبداً. إذا رأيته، فشرطك على الأرجح لم يصر خطأً أبداً.

### 1.9 دوالك الخاصة بـ def

الدالة عملية حسابية لها اسم ومعاملات:

```epher
def f(x) = x ^ 2
```

ثم استخدمها:

```epher
f(7)
```

```text
49
```

يمكن أن تأخذ الدوال عدة معاملات:

```epher
def area(w, h) = w * h
area(3, 4)
```

```text
12
```

يمكنك أيضاً تعريف دالة دون معاملات:

```epher
def answer() = 42
answer()
```

```text
42
```

### 1.10 العودية: دالة تستدعي نفسها

المثال الأشهر هو أرقام فيبوناتشي:

```epher
def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
```

```epher
fib(10)
```

```text
55
```

`fib(10)` هو رقم فيبوناتشي العاشر. تستدعي الدالة نفسها بوسائط أصغر حتى تصل إلى `n <= 1`. ينجح هذا لأن صيغة `if ... then ... else ...` تحسب الفرع الذي تحتاجه فقط.

> جسم الدالة تعبير واحد، سطر واحد. لدمج عدة عمليات حسابية استخدم `;` في نص برمجي بدلاً من ذلك (القسم التالي).

### 1.11 النصوص البرمجية: عدة عبارات دفعة واحدة

*النص البرمجي* هو عدة عبارات مربوطة بـ `;` أو بأسطر جديدة، تعني الشيء نفسه تماماً، تُنفَّذ واحدة تلو الأخرى:

```epher
x = 10; y = x + 5; x + y
```

```text
25
```

النصوص البرمجية هي طريقة بناء البرامج الصغيرة: جهّز المتغيرات، وأدر الحلقات، واعرض النتيجة النهائية.

الأسطر الجديدة و`;` هما الفاصل نفسه، ويمكنك خلطهما بحرية. زر **نسخ** الموجود فوق المثال ينسخ النص البرمجي كاملاً، ويمكنك لصقه مباشرة في epher: حقل الإدخال في تطبيق الويب وتطبيق سطح المكتب، وواجهة الطرفية، و`epher repl` جميعها تشغّل كل سطر بالترتيب، تماماً كما لو كنت كتبتها واحدة تلو الأخرى. ربط عدة عبارات بـ `;` في سطر واحد يعمل في كل مكان أيضاً، بما في ذلك وضع لمرة واحدة (القسم 4.1).


يمكن أن تحمل البرامج النصية **تعليقات** - ملاحظات لك يتخطاها epher، مكتوبة بأسلوب PHP. الرمز `//` أو `#` يعلّق حتى نهاية السطر، و`/* ... */` يعلّق على كتلة، عبر أسطر أو بين الرموز:

```epher
// a small script with notes
r = 3 # radius in metres
area = /* pi r squared */ pi * r ^ 2
area
```
### 1.12 نتائج دقيقة: frac وdec وbig

عادة يحسب epher بأرقام عشرية مثل الآلة الحاسبة الجيبية. بعض الأرقام أجمل بصيغة دقيقة.

**frac(n, d)** ينشئ كسراً دقيقاً:

```epher
1 / 3
```

```text
0.3333333333333333
```

```epher
frac(1, 3)
```

```text
1/3
```

تبقى الكسور دقيقة عبر العمليات الحسابية:

```epher
frac(1, 3) * 3
```

```text
1
```

**dec(x)** ينشئ عدداً عشرياً دقيقاً. قارن هذين:

```epher
0.1 + 0.2
```

```text
0.30000000000000004
```

```epher
dec(0.1) + dec(0.2)
```

```text
0.3
```

النتيجة الأولى هي خطأ التقريب الصغير الذي يرتكبه كل حاسوب مع الأعداد العشرية. `dec()` يزيله.

**big(x)** ينشئ عدداً صحيحاً دقيقاً، للقيم الأكبر من نطاق الآلة الحاسبة الجيبية:

```epher
big(10 ^ 20)
```

```text
100000000000000000000
```

تكتب **الأنظمة العددية** الأعداد الصحيحة كما يكتبها مجتمع الرياضيات:
`0b` للثنائي، `0o` للثماني، `0x` للسداسي عشري (البادئة تغير التهجئة
فقط، وليس القيمة أبدًا):

```epher
0b1010 + 0xFF
```

```text
265
```

حوّل بالعكس باستخدام **bin(x)** و**oct(x)** و**hex(x)**. تُعطي التهجئة
ذات البادئة لعدد صحيح، جاهزة للاستخدام مباشرة من جديد:

```epher
hex(255)
bin(10)
```

```text
0xff
```
0b1010
```

**exact(x)** يعيد بناء الكسر الدقيق وراء نتيجة عشرية: أي قيمة لها كسر جيد بمقام صغير تُعرض هكذا. هذا هو نفس إعادة البناء التي تستخدمها التطبيقات افتراضياً، لذلك يظهر `1 / 3` عادة مباشرة `1/3`:

```epher
exact(0.3333333333333333)
exact(0.30000000000000004)
```

```text
1/3
3/10
```

القيمة غير النسبية مثل `pi` لا تملك كسراً جيداً، لذا يتركها `exact()` كما هي.

أفعال العرض تكتب الرقم بترميز آخر. **scientific(x)** يستخدم رقماً واحداً قبل الأس، **engineering(x)** أسساً بخطوات ثلاث (يظل الجزء العشري بين 1 و1000)، و**grouped(x)** يدرج مسافات رفيعة كفواصل للآلاف:

```epher
scientific(12345)
engineering(12345)
engineering(0.5)
grouped(1234567.89)
```

```text
1.2345e4
12.345e3
500e-3
1 234 567.89
```

تقدم تطبيق الويب وTUI هذه الخيارات أيضاً كإعدادات عرض (انظر الفصلين 2.2 و5.2): كسور مضبوطة مفعلة أو معطلة، ترميز تلقائي/علمي/هندسي، وفواصل الآلاف. الإعدادات تغير طريقة عرض النتائج فقط؛ تبقى القيم تحتها أعداداً عشرية عادية.

### ### 1.13 الدوال المدمجة

لدى epher دوال آلة حاسبة علمية، مجمّعة حسب العائلة.

حساب المثلثات بالراديان. استخدم `deg` و`rad` للتحويل:

| الدالة | المعنى | مثال | النتيجة |
|---|---|---|---|
| `sin(x)`، `cos(x)`، `tan(x)` | الدوال المثلثية | `sin(pi / 2)` | `1` |
| `asin(x)`، `acos(x)`، `atan(x)` | الدوال المثلثية العكسية | `atan(1)` | `0.7853981633974483` |
| `atan2(y, x)` | زاوية النقطة (x, y) | `atan2(1, 1)` | `0.7853981633974483` |
| `deg(x)` | راديان ← درجات | `deg(pi)` | `180` |
| `rad(x)` | درجات ← راديان | `rad(180)` | `3.141592653589793` |
| `sinh(x)`، `cosh(x)`، `tanh(x)` | الدوال الزائدية | `sinh(1)` | `1.1752011936438014` |
| `asinh(x)`، `acosh(x)`، `atanh(x)` | الزائدية العكسية | `acosh(1)` | `0` |

الأسس والجذور واللوغاريتمات (على الآلات الحاسبة `log` أساسه 10):

| الدالة | المعنى | مثال | النتيجة |
|---|---|---|---|
| `sqrt(x)` | الجذر التربيعي | `sqrt(16)` | `4` |
| `cbrt(x)` | الجذر التكعيبي | `cbrt(-27)` | `-3` |
| `root(n, x)` | الجذر النوني | `root(3, 8)` | `2` |
| `exp(x)` | e مرفوعة للقوة x | `exp(1)` | `2.718281828459045` |
| `ln(x)` | اللوغاريتم الطبيعي | `ln(e)` | `1` |
| `log(x)` | لوغاريتم أساس 10 | `log(100)` | `2` |
| `log2(x)` | لوغاريتم أساس 2 | `log2(8)` | `3` |
| `logb(b, x)` | لوغاريتم بالأساس b | `logb(2, 8)` | `3` |
| `hypot(a, b)` | الوتر | `hypot(3, 4)` | `5` |
| `5!` (وأيضاً `fact(n)`) | مضروب | `5!` | `120` |

التقريب والإشارات والأعداد الصحيحة:

| الدالة | المعنى | مثال | النتيجة |
|---|---|---|---|
| `abs(x)` | القيمة المطلقة | `abs(-3)` | `3` |
| `floor(x)` / `ceil(x)` | تقريب لأسفل / لأعلى | `floor(2.7)` | `2` |
| `round(x)` | الأقرب، والنصف يبتعد عن الصفر | `round(2.5)` | `3` |
| `trunc(x)` | حذف الجزء العشري | `trunc(-2.9)` | `-2` |
| `sign(x)` | -1 أو 0 أو 1 | `sign(-5)` | `-1` |
| `ncr(n, r)` | التوافيق | `ncr(52, 5)` | `2598960` |
| `npr(n, r)` | التباديل | `npr(5, 2)` | `20` |
| `gcd(a, b)` / `lcm(a, b)` | القواسم والمضاعفات المشتركة | `gcd(12, 18)` | `6` |
| `mod(a, b)` | الباقي | `mod(7, 3)` | `1` |

الأعداد الأولية والقواسم تعمل على الأعداد الصحيحة:

| الدالة | المعنى | مثال | النتيجة |
|---|---|---|---|
| `isprime(n)` | صحيح إذا كان n أوليًا | `isprime(97)` | `true` |
| `nextprime(n)` / `prevprime(n)` | أقرب الأعداد الأولية | `nextprime(10)` | `11` |
| `factors(n)` | تحليل إلى عوامل أولية | `factors(360)` |
| حرفية قائمة | `{…}` | `{1, 2, 3}` |
| عنصر قائمة | `list[i]` (يبدأ من 1) | `{5, 6}[2]` |
| إحصاء قائمة | `mean(قائمة)`, `median(قائمة)`, … | `stdev(d)` |
| شكل قائمة | `len(s)`, `sort(s)`, `mode(s)`, `range(s)`, `quartile(s, k)` | `quartile(d, 1)` |
| انحدار خطي | `linreg(xs, ys)` | `linreg(x, y)` |
| عائلة طبيعية | `normpdf` `normcdf` `invnorm` | `invnorm(0.975)` |
| عائلة t | `tpdf` `tcdf` `invt` | `invt(0.975, 10)` |

### 1.16 الفلك والمجموعة الشمسية

يتحدث epher لغة الفلك: لواحق الوحدات، والثوابت الفيزيائية، ودوال التقويم
والوقت، وفلك حي للشمس والقمر والكواكب وبلوتو. وكل ذلك يعمل دون اتصال.

**وحدات تتحدث الفلك.** اكتب رقمًا يتبعه لاحقة وحدة وسيحوّله epher فورًا إلى
وحدات النظام الدولي:

| اللاحقة | الوحدة | تُحوِّل إلى |
|---|---|---|
| `AU` أو `au` | الوحدة الفلكية | أمتار |
| `pc` | فرسخ فلكي | أمتار |
| `ly` | سنة ضوئية | أمتار |
| `deg` | درجة | راديان |
| `arcmin`, `arcsec` | دقيقة وثانية قوسية | راديان |
| `min`, `hr`, `d`, `yr` | دقيقة، ساعة، يوم، سنة يوليوسية | ثوانٍ |
| `Jy` | جانسكي | واط/م²/هرتز |

```epher
3.2 AU in m
```

```text
478713186240 m
```

```epher
sin(30 deg)
```

```text
0.5
```

اللواحق جزء من قواعد اللغة، فلا يمكن لأي ثابت من المستخدم أن يغيّر معنى
`3.2 AU`، ويبقى `h` ثابت بلانك: تُكتب الساعات `hr`. تعيد الدوال عددًا بوحدات
طبيعية؛ واللاحقة تحوّل العدد إلى النظام الدولي، فـ `mag2jy(20)` عدد بالجانسكي
و`mag2jy(20) Jy` هو التدفق نفسه بالواط لكل متر مربع لكل هرتز.

**الثوابت الفلكية.** تعمل `au` و`pc` و`ly` و`c` و`g` و`h` و`h_bar` و`k_b`
و`sigma_sb` و`m_sun` و`r_sun` و`l_sun` و`m_earth` و`r_earth` و`m_moon` و`r_moon` مثل `pi`، ويمكنك
تظليلها بثوابتك الخاصة.

**التواريخ والوقت.** تحوّل `jd(y, m, d [, hr])` و`mjd(...)` تاريخًا ميلاديًا
إلى تاريخ يوليوسي، وتقرأ `now()` اللحظة الحالية:

```epher

```

```text
2451545
```

و`delta_t(jd)` هي تصحيح TT - UT1، و`lst(jd, lon)` هي الوقت النجمي المحلي
بالساعات لخط طول شرقي بالدرجات.

**الساعات والدقائق والثواني.** تحوّل `hms2deg(h, m, s)` المطلوع المستقيم إلى
درجات، و`dms2deg(d, m, s)` زاوية سكساجينيسيمية، و`deg2hms(x)` / `deg2dms(x)`
تكتبان الزاوية نصًا:

```epher

```

```

**السماء بأرقام.** أعطِ كل دالة وصول رقمًا للجرم: عطارد 1، الزهرة 2، المريخ 4،
المشتري 5، زحل 6، أورانوس 7، نبتون 8، بلوتو 9، الشمس 10، القمر 11 (الأرض هي 3،
المرصِد، وليست هدفًا أبدًا).

| الدالة | المعنى |
|---|---|
| `ra(b, jd)`, `decl(b, jd)` | المطلوع المستقيم والميل المركزي-الأرضي (درجات) |
| `dist(b, jd)` | المسافة بالوحدات الفلكية |
| `alt(b, jd, lat, lon)`, `az(b, jd, lat, lon)` | الارتفاع والسمت الأعلى-المركزيان (درجات، حقيقيان) |

### 1.18 حل المعادلات

**solve** يجد جذور معادلة في متغير واحد. تستخدم المعادلة `==`:

```epher
solve x^2 == 5*x + 6
```

```text
x = -1, x = 6
```

المعادلات متعددة الحدود (المبنية من `+ - * ^` والثوابت) تعطي كل جذر، حقيقياً ومركباً:

```epher
solve x^2 == -1
solve x^2 + 2*x + 5 == 0
solve (x - 1)^2 == 0
```

```text
x = -i, x = i
x = -1-2i, x = -1+2i
x = 1
```

المتغير المطلوب حله هو `x` عند ظهوره، وإلا المتغير الوحيد الآخر. تعمل الثوابت والمتغيرات المرتبطة كمعاملات:

```epher
const k = 3
solve k*x == 12
```

```text
x = 4
```

أي معادلة أخرى تُمسح عددياً على -100..100: تُحصر الجذور بتغيرات الإشارة، لذلك يسرد `solve sin(x) == 0.5` كل جذر في ذلك النطاق. حدان صريحان: جذر تلمس فيه الدالة الصفر فقط (مثل `x^2 == 0` عبر المسار العددي) قد يُفوَّت، والمعادلات ذات متغيرات متعددة غير مرتبطة خطأ.

### 1.19 التفاضل والتكامل: المشتقة والتكامل

**derivative(expr, p)** هي المشتقة العددية لـ`expr` عند `p`. يبقى الوسيط الأول تعبيراً، ومتغيره الحر هو الذي يُفاضَل:

```epher
derivative(x^2, 3)
derivative(sin(t), 0)
```

```text
6
1
```

لأن الوسيط يبقى تعبيراً، يمكن رسم المشتقة: `graph derivative(x^3 - x, x)` يرسم منحنى الميل.

**integral(expr, a, b)** هو التكامل المحدد من `a` إلى `b`، محسوباً بتربيع سيمبسون التكيفي:

```epher
integral(x^2, 0, 3)
integral(sin(x), 0, pi)
```

```text
9
2
```

`integral(x^2, 3, 0)` تساوي `-9` (التكامل بإشارته)، وحد علوي قابل للرسم يعمل: `graph integral(x^2, 0, x)`.

كلاهما عددي؛ يجب أن تكون التعبيرات حقيقية القيمة عبر النطاق، والتعبير ذو متغيرات متعددة خطأ.

### 1.20 البيانات: القوائم والإحصاء والانحدار

القائمة هي عمود من الأرقام بين قوسين معقوفين: `{1, 2, 3}`. العناصر هي
تعبيرات، والقائمة الفارغة `{}` مسموحة، والقائمة ترتبط باسم مثل أي قيمة:

```epher
d = {12, 15, 14, 16, 13, 15, 14, 17}
d[2]
len(d)
```

`list[i]` هو العنصر رقم i، يبدأ العد من 1 كما في الآلة الحاسبة؛
المؤشر خارج القائمة خطأ. القوس المربع يلتصق أقوى من `^`، لذا `d[2]^2`
هي `(d[2])^2`.

العمليات الحسابية على القائمة عنصرًا بعنصر، ويُطبَّق الرقم المفرد على
كل عنصر:

```epher
{1, 2, 3} * 2
{1, 2, 3} + 10
```

يجب أن يكون طولا القائمتين متساويين في `+ - * / ^`. يقارن `==` و
`!=` القائمتين كاملتين؛ ومقارنات الترتيب ترفض القوائم.

تأخذ دوال الإحصاء قائمة واحدة كوسيط وحيد (الصيغة متعددة الوسائط باقية —
`mean(1, 2, 3)` ما زالت تعمل): `sum product mean median mode variance
stdev min max range`. دوال الشكل الجديدة هي `len(قائمة)` و`sort(قائمة)`
(نسخة تصاعدية) و`mode(قائمة)` (القيمة الأكثر تكرارًا، والأصغر عند
التعادل) و`range(قائمة)` (أكبر ناقص أصغر قيمة) و`quartile(قائمة, k)`
حيث k من 1 إلى 3 (ربيعيات بأسلوب TI، وسيط النصفين):

```epher
mean(d)
median(d)
quartile(d, 1)
```

**linreg(xs, ys)** يلائم خط المربعات الصغرى لقائمتين متساويتي الطول
ويُبلغ عنه مع معامل الارتباط r:

```epher
linreg({1, 2, 3, 4}, {2.1, 4.2, 5.8, 8.1})
```

الخط الملائم عرضٌ، مثل جذور solve؛ صورة الملاءمة تعيش في مخطط
التشتت (القسم 1.22).

### 1.21 التوزيعات واختبارات الفرضيات

تغطي دوال الاحتمال التوزيع الطبيعي المعياري و t لستودنت وكاي تربيع
وذات الحدين وبوزون. تأخذ عائلة التوزيع الطبيعي وسيطًا واحدًا أو
ثلاثة — الوسيط الواحد هو الطبيعي المعياري:

```epher
normcdf(1.96)
invnorm(0.975)
normcdf(12, 10, 2)
```

`normpdf(x[, mu, sigma])` و`normcdf(x[, mu, sigma])` و`invnorm(p[,
mu, sigma])`؛ و`tpdf(x, df)` و`tcdf(x, df)` و`invt(p, df)`؛
و`chi2pdf(x, df)` و`chi2cdf(x, df)` و`invchi2(p, df)`؛
و`binompdf(k, n, p)` و`binomcdf(k, n, p)`؛ و`poissonpdf(k, lambda)`
و`poissoncdf(k, lambda)`. تجيب دوال `inv*` عن السؤال المعاكس:
`invt(0.975, 10)` هي قيمة t التي تحتها 97.5% من الكتلة.

تأخذ الاختبارات قائمة بيانات وتُبلغ عن الإحصاء وقيمة p ثنائية الجانب
كنص عرض؛ وتُبلغ الفترات عن `(أسفل, أعلى)` عند المستوى الذي تسميه:

```epher
d = {12, 15, 14, 16, 13, 15, 14, 17}
ttest(d, 14)
tinterval(d, 0.95)
ztest(d, 14, 1.5)
chisq_gof({20, 30, 25, 25}, {25, 25, 25, 25})
```

يستخدمان `ttest(بيانات, mu0)` و`tinterval(بيانات, مستوى)` الانحراف
المعياري للعينة (n−1)؛ ويحتاجان `ztest(بيانات, mu0, sigma)` و
`zinterval(بيانات, sigma, مستوى)` إلى sigma معلوم. و`chisq_gof(ملاحظ,
متوقع)` هو اختبار جودة المطابقة بدرجات حرية k−1. النتائج نصوص عرض:
قابلة للقراءة والنسخ، لكن الحساب لا يلمسها.

الصندوق. يحتكر مخطط البيانات اللوحة مثل النظام الشمسي — أحدث أمر
يفوز، و`graph clear` يفرغه.

```epher
x = {1, 2, 3, 4, 5}
y = {2.1, 4.2, 5.8, 8.1, 9.9}
graph scatter(x, y)
```

```epher
graph histogram({1, 2, 2, 3, 3, 3, 4, 5})
```

```epher
graph boxplot({1, 2, 2, 3, 3, 3, 9})
```

**scatter(xs, ys)** يرسم النقاط، وعند وجود نقطتين أو أكثر يرسم خط
المربعات الصغرى، بعنوان `y = a*x + b (r = …)` في المفتاح.
**histogram(بيانات[, خانات])** يرسم مدرجًا تكراريًا؛ عدد الخانات
اختياري (قاعدة ستيرجس افتراضيًا) ويجب أن يكون عددًا صحيحًا بين 1 و50.

### 1.23 أعداد عشوائية

`random()` يسحب عددًا منتظمًا في `[0, 1)`، و`random(a, b)` واحدًا في `[a, b)`،
و`randint(a, b)` عددًا صحيحًا من الفترة المغلقة `[a, b]` — رمية نرد:

```epher
randseed(7)
randint(1, 6)
```

```text
7
3
```

التسلسل قابل لإعادة الإنتاج: يعيد `randseed(n)` بذر المولّد بـ `n` ويعرضه،
لذلك نفس البذرة تعيد نفس السحوبات في كل جلسة وكل واجهة.

### 1.24 الوحدات والتحويل

الرقم الذي يتبعه وحدة يصبح *كمية*: القيمة بوحدات SI بالإضافة إلى أبعادها.
يغطي جدول الوحدات وحدات SI الأساسية والمشتقة (`m`, `s`, `kg`, `A`, `K`,
`mol`, `cd`, `Hz`, `N`, `Pa`, `J`, `W`, `C`, `V`, `F`, `ohm`, `S`,
`Wb`, `T`, `H`, `lm`, `lx`, `Bq`, `Gy`, `Sv`)، والوحدات اليومية (`min`,
`hr`, `d`, `yr`, `L`, `t`, `bar`, `atm`, `torr`, `psi`, `eV`, `mile`,
`yd`, `ft`, `inch`, `nmi`, `lb`, `oz`, `gal`, `qt`, `pt`, `mph`,
`knot`)، ولواحق الفلك من القسم 1.16. الوحدات المركبة تتسلسل: `60
mile/hr` و`5 m/s^2` وحدتان مفردتان.

```epher
60 mile/hr
```

```text
60 mile/hr
```

سوابق SI تدرّج أيًا منها: `k M G T m µ n p` هي كيلو وميجا وجيجا وتيرا
وميلي وميكرو ونانو وبيكو — `5 km` و`3 MPa` و`1 GHz` تعمل جميعًا،
و`2 kg` هو الكيلوجرام نفسه.

تُفحص الأبعاد: جمع أو مقارنة كميات بوحدات مختلفة ينتج خطأً بدل خلط
الأمتار والثواني:

```epher
5 m + 3 s
```

```text
error: dimension error: cannot add 5 m and 3 s
```

الحساب يركّب الأبعاد: `5 m * 3 m` هي `15 m^2`، و`(3 m)^2` هي `9 m^2`،
و`sqrt(4 m^2)` هي `2 m`، والتعبير الكامل الذي تتلاشى أبعاده يعود عددًا
عاديًا (`5 m / 5 m` هو `1`). تفضّل النتائج الاسم المشتق الدقيق عندما
تطابقه الأبعاد — `5 kg * 3 m / 1 s^2` يجيب `15 N`.

**التحويل.** `expr in وحدة` (أو `expr -> وحدة`) يعرض كمية بالوحدة
المذكورة؛ يجب أن تتطابق الأبعاد. `in` أضعف الروابط بين العوامل، لذا
`5 m + 3 m in km` يحوّل المجموع كاملًا:

```epher
72 km/hr in m/s
```

```text
20 m/s
```

```epher
2 m^2 in cm^2
```

```text
20000 cm^2
```

مقاييس الحرارة (سلسيوس، فهرنهايت) ليست وحدات هنا — الكلفن وحدة، و`K`
تعمل مثل أي وحدة أخرى.


### 1.25 العمليات الثنائية

الرموز الأساسية من القسم 1.13 مصنوعة لهذا: `0b101` و`0o17` و`0xFF`. عوامل
البت تعمل على الأعداد الصحيحة وتجيب بأعداد صحيحة دقيقة:

```epher
0xFF & 0x0F
```

```text
15
```

| العامل | المعنى |
|---|---|
| `a & b` | و على مستوى البت |
| `a \| b` | أو على مستوى البت |
| `a xor b` | أو الحصري على مستوى البت |
| `~a` | نفي على مستوى البت (متمم الثنائي) |
| `a << n` | إزاحة يسار (ضرب في 2^n) |
| `a >> n` | إزاحة يمين حسابية (قسمة على 2^n، تقريب لأسفل) |

النتائج أعداد صحيحة `big` دقيقة، لذا `1 << 60` يحتفظ بكل رقم. حجم الكلمة
الافتراضي 64 بت: تُقرأ النتائج كمتمم ثنائي مع الإشارة، لذا `~0` هو -1
و`1 << 100` يلتف إلى 0. يغيّر `bits(n)` حجم الكلمة إلى 8 أو 16 أو 32 أو
64، و`bits()` يعرضه:

```epher
bits(8)
~0
```

```text
8
-1
```

الإزاحة بمقدار سالب تعكس الاتجاه (`8 << -1` هو `4`). يحتفظ `and` و`or`
المنطقيان بمعناهما؛ `&` و`|` هما كتابتا البت.


### 1.26 العلاقات الضمنية

المعادلة ذات المجهولين تُرسم كمنحنى: عائلة الرسوم تأخذ عينات من العلاقة بطريقة المربعات المتحركة وترسم محيط الصفر. الدائرة والقطع المكافئ والخط الرأسي — كل واحد بأمر واحد:

```epher
graph x^2 + y^2 == 1
```

```epher
graph y == x^2
```

```epher
graph x == 2
```

تُؤخذ عينات العلاقة على مربع `from a to b` (أو النافذة الافتراضية)، لذا `graph x^2 + y^2 == 1 from -2 to 2` يلائم نافذة الدائرة. كل ما يفعله المنحنى ينطبق: وسيلة الإيضاح تعرض المعادلة، والمنزلقات تحرك ثوابتها، والصورة تُكبَّر وتُحرَّك وتُصدَّر مثل أي رسم. تعبئات المتباينات (`y < …`, `y > …`) تبقى منحنيات مظللة؛ العلاقة لا نقاط اهتمام لها.


## 2. تطبيق الويب (PWA)

### 2.1 فتحه

تطبيق الويب موجود على:

```text
https://epher.org/pwa/
```

لا حاجة للتثبيت. يعمل في أي متصفح حديث على الحاسوب أو الهاتف أو الجهاز اللوحي.

هذا الدليل مدمج أيضاً في التطبيق: افتح **Help → User guide** في شريط القوائم (المس **☰** على الهاتف) لقراءته داخل التطبيق، بلغة التطبيق الحالية. المس أي مثال في ذلك الدليل لتحميله في حقل الإدخال. يفتح **المساعدة → الثوابت** مستعرض الثوابت: كل ثابت مدمج في مجموعات (رياضيات، فلك، فيزياء، كيمياء)، كل واحد بقيمته ووصف مختصر؛ المس واحدًا لإدراج اسمه في حقل الإدخال، ويصفّي صندوق البحث القائمة.

### 2.2 أول عملية حساب لك

1. انقر حقل النص (يكون مركَّزاً بالفعل عند تحميل الصفحة).
2. اكتب تعبيراً، مثلاً `2 + 3 * 4`.
3. اضغط **Enter** أو انقر زر **=**.

تظهر النتيجة بخط كبير أسفل الحقل. كل ما في الفصل 1 يعمل هنا، بما في ذلك المتغيرات والدوال والنصوص البرمجية.

أثناء كتابة اسم، تظهر قائمة اقتراحات أسفل الحقل: الأسهم تحرك التحديد، و**Enter** أو **Tab** يقبل، و**Esc** يغلق، والنقرة تقبل دون مغادرة لوحة المفاتيح. كل اقتراح يحمل وصفاً موجزاً للدالة أو الثابت. و**F1** يعرض الوصف نفسه للكلمة عند المؤشر في شريط التلميحات فوق لوحة المفاتيح. وإذا كان أول ما تكتبه في حقل فارغ عاملًا (`+ - * / ^ % !`)، يضيف epher‏ `ans` تلقائياً، فيكمل السطر من الإجابة السابقة.

تحتوي قائمة **الإعدادات** (أيقونة الترس، أو **☰ → الإعدادات** على الهاتف) على ثلاث مجموعات. **المظهر** و**اللغة** يفعلان ما يعنيه اسماهما. **النتائج** تشكل عرض الإجابات: كسور مضبوطة (مفعلة افتراضياً، لذا يظهر `1 / 3` كـ`1/3`)، الترميز (تلقائي أو علمي أو هندسي)، وفواصل الآلاف. هذه إعدادات عرض فقط؛ تبقى القيم تحتها أعداداً عادية.

### 2.3 السجل

تُضاف كل عملية حساب إلى قائمة السجل أسفل النتيجة، لتتمكن من التمرير للخلف ورؤية ما فعلته. تظهر أحدث الإدخالات في الأعلى، وأيقونة سلة المهملات بجانب عنوان **السجل** تفرغها (في الطرفية، Ctrl+L أو نقرة على الأيقونة نفسها). يبقى السجل ما دامت الصفحة مفتوحة.

يقع كل عنصر بين خطوط رفيعة: التعبير ذو السطر الواحد هو صف واحد، والنص البرمجي متعدد الأسطر هو عنصر واحد يعرض كل أسطره. انقر على عنصر لإعادته إلى حقل الإدخال وتشغيله من جديد.

### 2.4 الرسوم البيانية

اكتب `graph` متبوعاً بتعبير، ثم اضغط **Enter**:

```epher
graph x ^ 2
```

يرسم epher المنحنى y = f(x) من x = −10 إلى x = 10 أسفل حقل الإدخال، على شبكة ذات محاور معنونة. يمكنك رسم أي تعبير، بما في ذلك دوالك الخاصة:

```epher
def f(x) = x ^ 3
graph f(x)
```

كل سطر `graph` يضيف منحنى آخر إلى المخطط نفسه، لكلٍّ لونه الخاص. المنحنيات كلها مصمتة، والوسيلة الإيضاحية والتسميات
هي ما يميّزها دون لون. `graph clear` يفرغ المخطط، وزر **Clear graph** أعلى لوحة الرسم البياني يفعل الشيء نفسه للمنحنيات والأسطح 3D معاً. تحتفظ واجهة الطرفية بالأمر في قائمة **Graph** الخاصة بها.

في أعلى لوحة الرسم البياني، بجانب **Clear graph** و**Copy SVG**،
يتيح شريط الأدوات إخفاء قائمة نقاط الاهتمام والنقاط المميزة المرسومة
على الرسم نفسه. فوق كل رسم مباشرة يوجد شريط من المنزلقات المعنونة
بالأيقونات، والكلمات في تلميح كل واحد منها: سماكة الخط (من 0 إلى 4
بخطوات 0.1 للمنحنيات 2D، ومن 0 إلى 0.2 بخطوات 0.01 للأسطح 3D - لا
يُعرض إلا مزلج النوع المعروض، وكل نوع يحفظ قيمته الخاصة)، وفي
العرضين 3D والشمسية سرعة الدوران الأفقي والرأسي وسرعة التقريب. أمام كل مدخل في الوسيلة
الإيضاحية خانة اختيار، محددة افتراضيًا: إلغاء تحديدها يخفي المنحنى من
الرسم ومن نقاط اهتمامه ومن تصدير SVG.

```epher
graph x ^ 2
graph x ^ 3
```

النقاط التي لا يكون للتعبير فيها قيمة (القسمة على صفر مثلاً) تُتجاوز، تاركة فجوة في المنحنى. والقفزة التي هي في الحقيقة خط تقارب رأسي لا تُرسم أبداً كخط واصل.

#### 2.4.1 ما يمكنك رسمه

مجال من اختيارك:

```epher
graph sin(x) from 0 to 2*pi
```

منحنيات وسيطية (تمتد t من 0 إلى 2π):

```epher
graph param 2*cos(t), 3*sin(t)
```

منحنيات قطبية:

```epher
graph polar 1 + cos(theta)
```

مناطق: `y <` يظلّل المنطقة تحت المنحنى، و`y >` يظلّل فوقه:

```epher
graph y < x ^ 2
```
#### 2.4.2 قراءة المخطط

**التتبع:** حرّك المؤشر فوق المخطط، أو ركّز عليه واضغط مفاتيح الأسهم. فيُعلَّم أقرب نقطة على المنحنى، وتُعرض إحداثياتها أسفل المخطط.

**نقاط الاهتمام:** بعد كل أمر graph يجد epher جذور كل منحنى ونقاط تحوّله وتقاطعات المنحنيات، يعلّمها على المخطط، ويعرضها أسفله:

```text
root (-1, 0)   minimum (0, 0)   root (1, 0)
```

**الجداول:** أمر `table` يطبع جدول قيم (الصفوف التي لا قيمة للتعبير فيها تبقى فارغة):

إضافة اختيارية `derivative <تعبير>` تضيف عمودًا ثالثًا، وهو المشتقة
العددية لذلك التعبير عند كل x:

```epher
table x ^ 2 from -2 to 2 points 5 derivative x ^ 2
```

```text
         x           y          y'
        -2           4          -4
        -1           1          -2
         0           0           0
         1           1           2
         2           4           4
```

تتبع خلايا الجدول إعدادات النتائج: مع تشغيل الكسور الدقيقة
(الافتراضي)، تظهر القيمة التي هي كسر بسيط ككسر — يسرد `table x / 3
from 0 to 1 points 4` قيمة `1/3` بدلًا من `0.333`.
```epher
table x ^ 2 from -2 to 2 points 5
```

```text
         x           y
        -2           4
        -1           1
         0           0
         1           1
         2           4
```

#### 2.4.3 المنزلقات والتصدير

عرّف ثابتاً واستخدمه في رسم بياني، فيظهر منزلق أسفل المخطط. اسحبه (أو حرّكه بمفاتيح الأسهم) ويُعاد رسم كل منحنى:

```epher
const a = 1
graph a * x ^ 2
```

ينسخ **Copy SVG** المخطط الحالي كصورة SVG مستقلة للصقها في المستندات.
الألوان مدمجة فيه، فيبدو نفسه في كل مكان.**حفظ PNG** يحفظ الصورة نفسها كصورة نقطية بضعف الحجم، فيبقى المنحنيات واضحة؛ يطلب تطبيق سطح المكتب مكان الحفظ، ويحفظ تطبيق المتصفح في مجلد التنزيلات (أو يطلب، حيث يتيح المتصفح ذلك). صفوف المزالق والثوابت المتحركة
تقع مباشرة أسفل الرسم، فوق قائمة نقاط الاهتمام.

#### 2.4.4 الأسطح 3D

يرسم `graph3d` سطحاً z = f(x, y) فوق مجال مربع (من −5 إلى 5، أو `from a to b` الذي تحدده):

```epher
graph3d x ^ 2 - y ^ 2
```

تُرسم خطوط الشبكة الأقرب إليك بشكل أسمك، فيتضح عمق الشكل. تتراكب عدة أسطر `graph3d` فوق بعضها، مثل المنحنيات، و`graph3d clear` يفرغ المخطط. دوّر المنظر بالسحب، أو ركّز على المخطط واستخدم مفاتيح الأسهم. ترسم واجهة الطرفية السطح نفسه كإطار سلكي ASCII، وتدوّره مفاتيح الأسهم.

#### 2.4.5 التحريك

لكل منزلق زر تشغيل. يحرّك ثابته خطوة بخطوة عبر مدى المنزلق ثم يلتف ليعود إلى البداية. هذه هي الطريقة المعيارية التي تحرّك بها الآلات الحاسبة: تحرّك معاملاً، فيتحرك كل ما يستخدمه. اضغط الزر مرة أخرى للإيقاف المؤقت.

متغير "الوقت" هو مجرد ثابت تحرّكه:

```epher
const t = 0
graph sin(x - t)
```

تشغيل منزلق t يجعل الموجة تنتقل. تتحرك الأسطح 3D بالطريقة نفسها. حدّد ثابتاً أولاً، ثم شغّل منزلقَه:

```epher
const a = 1
graph3d sin(a * (x ^ 2 + y ^ 2)) from -3 to 3
```

في واجهة الطرفية، يبدأ شريط المسافة التحريك ويوقفه.

### 2.5 تثبيته واستخدامه دون اتصال

تطبيق الويب هو *تطبيق ويب تقدمي*: بعد زيارة واحدة يعمل بالكامل دون اتصال، ويمكنك تثبيته مثل تطبيق عادي.

- **Chrome أو Edge أو Android:** انقر أيقونة التثبيت في شريط العناوين (أو *Install app* في قائمة المتصفح)، ثم أكّد.
- **iPhone / iPad (Safari):** المس **Share** ← **Add to Home Screen**.
- **المتصفحات الأخرى:** ابحث عن *Install* أو *Add to Home Screen* في القائمة.

بمجرد تثبيته، شغّله من شاشتك الرئيسية أو قائمة التطبيقات. يفتح فوراً، حتى دون اتصال بالإنترنت.

### 2.6 ما لا يفعله تطبيق الويب

يحتفظ تطبيق الويب بعملك في الجلسة الحالية: يقيّم التعبيرات ويرسمها بيانياً (القسم 2.4) ويحتفظ بسجل. تعمل أوامر **save** و**save script** و**language** في إصدارات سطح المكتب وسطر الأوامر والطرفية (الفصول 3 و4 و5). في تطبيق الويب تجيب بملاحظة تفيد بأن الحفظ متاح هناك. لا يُحفظ السجل بين الزيارات.

## 3. تطبيق سطح المكتب

تطبيق سطح المكتب هو نافذة عادية حول نفس تطبيق الويب. كل ما في الفصل 2 ينطبق؛ الفرق فقط في طريقة التثبيت والتشغيل.

### 3.1 التثبيت

نزّل مثبِّتاً واحداً لنظامك من موقع epher:

- **Windows:** شغّل `epher-windows-x86_64.exe`. يضع المثبِّت `epher` في PATH. افتح نافذة CMD أو PowerShell جديدة و`epher "2 + 2"` يعمل. لأن البناء غير موقَّع، اختر *More info* ← *Run anyway* عند أول تشغيل.
- **macOS:** افتح ملف `epher-macos-aarch64.dmg` واسحب epher إلى Applications. لأن البناء غير موقَّع، يحتاج أول تشغيل إلى النقر بالزر الأيمن ← **Open**.
- **Linux (Debian/Ubuntu):** حزمة `.deb`

```sh
sudo apt install ./epher-linux-x86_64.deb
```

- **Linux (Fedora/RHEL):** حزمة `.rpm`

```sh
sudo dnf install ./epher-linux-x86_64.rpm
```

- **Linux (أي توزيعة، بما فيها Arch):** AppImage. اجعله قابلاً للتنفيذ وشغّله:

```sh
chmod +x epher-linux-x86_64.AppImage
./epher-linux-x86_64.AppImage
```

يحتوي كل مثبِّت على epher *كله*: تطبيق سطح المكتب وسطر الأوامر (الفصل 4) وواجهة الطرفية (الفصل 5)، بوصفها الأمر الواحد `epher`. على Linux، تضع الحزمة `epher` في `/usr/bin`.

### 3.2 الاستخدام

شغّل epher مثل أي تطبيق آخر. تحصل على نافذة بنفس واجهة تطبيق الويب: اكتب تعبيراً، واضغط **Enter** أو انقر **=**، واقرأ النتيجة. الرسوم البيانية تعمل هنا أيضاً. `graph x ^ 2` يرسم في النافذة (الفصل 2.4). يمكن تغيير حجم النافذة بحرية. يتضمن شريط القوائم **Help → User guide**، الدليل نفسه الذي في هذه الصفحة، مع أمثلة تُحمَّل باللمس.

يمكنك أيضاً فتحه من الطرفية: `epher` دون وسائط (أو `epher gui`) يبدأ تطبيق سطح المكتب. على macOS، استخدم زر **Install the epher command** داخل التطبيق لوضع `epher` في PATH الطرفية.

### 3.3 التخزين: مخزن واحد مشترك مع CLI وTUI

يشارك تطبيق سطح المكتب تخزينه مع إصدارَي سطر الأوامر والطرفية. الدوال والثوابت والنصوص البرمجية والسجل وتفضيل اللغة تعيش في مكان واحد، `~/.epher` على حاسوبك (أو `EPHER_STORE_DIR`، الفصل 4.6)، وكل ما يُحفظ في إصدار متاح في البقية:

```text
def area(w, h) = w * h
save area
```

عرّف `area` في تطبيق سطح المكتب، احفظها بأمر `save`، أغلق النافذة. ثم افتح CLI وستجد `area(3, 4)` تعمل مباشرة. ويعمل العكس أيضاً: عند فتح نافذة سطح المكتب تكون الدوال والنصوص البرمجية المحفوظة في CLI أو TUI موجودة بالفعل، بما في ذلك المتغيرات التي تضعها النصوص المحفوظة. أوامر `save` و`save script` و`language` من الفصل 4 تعمل هنا تماماً بالطريقة نفسها.

الأوامر التي تكتبها في CLI أو REPL أو TUI أو تطبيق سطح المكتب تنضم جميعها إلى السجل نفسه، والجلسة تنتقل معك أيضًا: المتغيرات التي تعيّنها وقيمة `ans` تتبعك من إصدار إلى التالي. المخزن المشترك حي: عندما يكون إصداران مفتوحين معًا، ينعكس أي تغيير في أحدهما فورًا في الآخر (تطبيق سطح المكتب وواجهة الطرفية يراقبان المخزن ويحدّثان أنفسهما تلقائيًا).

> تطبيق الويب في المتصفح هو الإصدار الوحيد الذي لا يستخدم هذا المخزن. كل جلسة تعيش منفصلة (الفصل 2.6).

## 4. سطر الأوامر (CLI)

CLI هو الجانب النصي من برنامج `epher` نفسه الذي يمثله تطبيق سطح المكتب. له ثلاثة أوضاع: تقييم لمرة واحدة، ونصوص برمجية عبر الأنابيب، وجلسة تفاعلية للعمل الأطول.

للحصول على المساعدة في أي وقت، شغّل `epher --help` (كل الأوامر، مع أمثلة)
أو `epher help` (الدليل الكامل؛ في حزم لينكس هذه هي صفحة `man epher`).

### 4.1 حسابات لمرة واحدة

مرِّر التعبير كوسيط:

```sh
epher "2 + 3 * 4"
```

```text
14
```

يمكنك فعل أي شيء في الفصل 1 يكون تعبيراً واحداً:

```sh
epher "if 3 > 2 then 10 else 20"
```

```text
10
```

التعبير الذي يبدأ بعلامة ناقص يعمل مباشرة:

```sh
epher "-2 + 5"
```

```text
3
```

وضع لمرة واحدة للنصوص البرمجية، من تعبير واحد وحتى برنامج كامل. تُطبع قيمة كل عبارة في سطرها الخاص:

```sh
epher "x = 10; x + 5"
```

```text
10
15
```

العبارات المربوطة بأسطر جديدة تعمل بالطريقة نفسها داخل الوسيط. كل ما في الفصل 1 متاح: المتغيرات والدوال والحلقات، كل شيء. والأسطر تتشارك جلسة واحدة، مثل نص عبر الأنابيب (القسم 4.2).

### 4.2 نصوص برمجية عبر الأنابيب

يقرأ `epher -` التعابير من الإدخال القياسي سطراً بسطر، كما تُستخدم لغات البرمجة النصية في الأنابيب:

```sh
printf "x = 3\nx * 10\n" | epher -
```

```text
= 3
= 30
```

كل ما في الفصل 1 يعمل، والأسطر تتشارك جلسة واحدة: دالة عُرِّفت في سطر مبكر متاحة لاحقاً، و`save` يكتب في المخزن نفسه كالعادة. تُطبع الأخطاء ويستمر النص. قد يضم السطر عدة عبارات مربوطة بـ `;`. الأسطر الجديدة و`;` تعني الشيء نفسه في كل مكان في epher.


يعمل الملف بالطريقة نفسها: `epher plots/sine.es` ينفّذ كل سطر من الملف بالترتيب ويطبع كل نتيجة. يُعامل الوسيط كملف عندما يسمّي ملفًا موجودًا ويحتوي على `.` أو `/` أو `\` - لذا يبقى `epher x` يقيّم الاسم `x`.
### 4.3 الجلسة التفاعلية (REPL)

ابدأها بـ `epher repl`:

```sh
epher repl
```

> `epher` دون وسائط يفتح تطبيق سطح المكتب (الفصل 3).

يعرض epher موجهه وينتظر:

```text

```

الآن اكتب أي شيء من الفصل 1، سطراً سطراً. تحتفظ المتغيرات بقيمها بين الأسطر:

```text
epher> x = 5
= 5
epher> x ^ 2
= 25
```

أمر `table` (القسم 2.4.2) يطبع جدول قيم هنا أيضاً:

```text
epher> table x ^ 2 from -2 to 2 points 5

        -1           1
         0           0
         1           1
         2           4
```

`graph save plot.svg` نفس صورة SVG التي يعطيها زر **Copy SVG** في تطبيق
الويب. ويحفظ `graph3d save file.svg` سطحًا ثلاثي الأبعاد بالطريقة نفسها.
وتعمل السطور نفسها في التقييم المفرد وفي السكربتات المُمرَّرة:
`epher "graph sin(x); graph save plot.svg"` رسم كامل في أمر واحد.

```text
epher> quit
```

يُتذكر سجلك: في المرة القادمة التي تشغّل فيها `epher repl`، ستجد أسطر الجلسة السابقة ما زالت موجودة.


ينفّذ الأمر `load` برنامجًا نصيًا - مسار ملف أو اسم برنامج حفظته بـ `save script` - سطرًا بسطر، تمامًا كأنك كتبته بنفسك:

```text
epher> load plots/sine.es
epher> load my_setup
```
### 4.4 حفظ الدوال والثوابت والنصوص البرمجية

عرّف دالة، ثم احفظها:

```text
epher> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
epher> save fib
saved fib
```

يحفظ أمر `save fib` الدالة على القرص. في المرة القادمة التي تبدأ فيها الجلسة، تكون `fib` معرَّفة مسبقاً:

```text
epher> fib(10)
= 55
```

تُحفظ الثوابت بالطريقة نفسها. `save` مع اسم الثابت:

```text
epher> const tax = 0.2
= 0.2
epher> save tax
saved tax
```

لحفظ نص برمجي كامل (آخر سطر كتبته) استخدم `save script`:

```text
epher> x = 0; while x < 5 do x = x + 1; x
= 5
epher> save script count_to_five
saved script count_to_five
```

تُنفَّذ النصوص البرمجية المحفوظة تلقائياً عند بدء epher، لذا كل ما تعرّفه جاهز لك.


يمكنك أيضًا تحميل برنامج محفوظ متى شئت بـ `load count_to_five`، أو إبقائه ملفًا عاديًا وتشغيل `load count_to_five.es`؛ و`epher count_to_five.es` يشغّله مباشرة من سطر الأوامر (القسم 4.2).
### 4.5 تغيير لغة الواجهة

تُختار لغة الواجهة من اللغات المضبوطة على جهازك. لتغييرها، اكتب `language` متبوعاً بواحدة من: `en`، `zh-CN`، `hi`، `es`، `fr`، `ar`، `de`، `pt`:

```text
epher> language fr
language set to fr
```

يُتذكر الاختيار للمرة القادمة. لاحظ: اللغة التي *تكتب* بها، لغة التعبيرات، تبقى نفسها دائماً، بأي لغة واجهة.

### 4.6 أين توجد بياناتك

تُخزَّن الدوال والنصوص البرمجية والسجل واختيار اللغة في مجلد واحد على حاسوبك:

```text
~/.epher
```

احذف هذا المجلد لتبدأ من الصفر تماماً. لاستخدام موقع آخر، اضبط متغير البيئة `EPHER_STORE_DIR` قبل تشغيل epher:

```sh
EPHER_STORE_DIR=/tmp/my-epher epher repl
```

## 5. واجهة الطرفية (TUI)

TUI هو نسخة ملء الشاشة من الجلسة التفاعلية، داخل طرفيتك. هو جزء من برنامج `epher` نفسه. ابدأه بـ:

```sh
epher tui
```

### 5.1 الشاشة

تنقسم الشاشة إلى لوحات:

- **تعبير**: مربع الإدخال (أعلى). يبدأ Shift+Enter سطرًا جديدًا؛
  وتحرّك مفاتيح الأسهم أو نقرة الفأرة المؤشر داخل النص.
- **النتيجة** الحالية أسفله مباشرة.
- **السجل**: كل سطر كتبته، مع جوابه.
- **الرسم البياني**: مخطط أمر `graph` (أسفل).
- سطر تلميحات يعرض اختصارات لوحة المفاتيح.

### 5.2 المفاتيح

| المفتاح | الإجراء |
|---|---|
| الكتابة | إضافة إلى التعبير عند المؤشر |
| **Enter** | تقييم النص البرمجي كله (يدخل الإدخال متعدد الأسطر كعنصر واحد في السجل) |
| **Shift+Enter** | بدء سطر جديد |
| **← → ↑ ↓** | تحريك المؤشر (مع إدخال فارغ: تدوير العرض 3D) |
| **Esc** | مسح سطر الإدخال |
| **F1** | وصف الدالة عند المؤشر (في سطر النتيجة) |
| **Ctrl+C** | خروج |
| **q** | خروج (عندما يكون الإدخال فارغاً) |
| **Arrow keys** | تدوير العرض 3D (عندما يكون الإدخال فارغاً) |
| **Space** | تشغيل/إيقاف التحريك (عندما يكون الإدخال فارغاً) |
| **F10** | فتح القوائم (File، Edit، Graph، Settings، Help) |
| **Tab** | تركيز لوحة المفاتيح الظاهرة دائمًا (أو السجل، من لوحة المفاتيح)؛ تبديل مجموعاتها (**Esc** يعيد التركيز إلى الكتابة) |
| **الفأرة** | انقر القوائم وعناصرها، وخلايا لوحة المفاتيح وتبويباتها، وسطور السجل (تحمّل التعبير)؛ اسحب لوحة الرسم للتدوير (3D) أو التحريك (2D)، وعجلة الفأرة للتقريب، والنقر المزدوج يعيد ضبط العرض |
| **Ctrl+L** | مسح السجل |

يفتح **المساعدة** الدليل المدمج، ومساعدة مفاتيح لوحة المفاتيح، ومستعرض ثوابت: الثوابت في مجموعات، والأسهم تختار صفًا، و**Enter** يُدرج اسمه في التعبير عند المؤشر، و**Esc** يغلق.

تحتوي مجموعات لوحة المفاتيح على كل دالة وثابت وأمر تدعمه اللغة: **trig** و**fn** و**num** و**0x** و**var**. تحمل مجموعة 0x التحويلات الدقيقة وتحويلات الأساس (`frac` و`dec` و`big` و`bin` و`oct` و`hex`) والمضروب `!`. أسهم الاتجاهات تحرك التحديد، و**Enter** يُدرج الرمز، و**Tab** يبدّل المجموعات. العامل في بداية سطر فارغ (أو المُدرج من لوحة المفاتيح) يضيف `ans` أولاً، فيكمل السطر من الإجابة السابقة.

تقدم قائمة **الإعدادات** نفس خيارات عرض النتائج التي يقدمها تطبيق الويب (كسور مضبوطة، ترميز، فواصل آلاف)، إلى جانب صفي المظهر واللغة.

### 5.3 الرسوم البيانية

اكتب `graph` متبوعاً بتعبير، ثم اضغط **Enter**:

```epher
graph x ^ 2
```

يأخذ epher عينات من المنحنى من x = −10 إلى x = 10 ويرسمه كمخطط ASCII في لوحة Graph؛ وسيلة الإيضاح فوق المخطط تسمّي ما يُرسم.

`graph clear` يفرغ المخطط، وقائمة **Graph** تفعل الشيء نفسه؛ قائمة **Help** تفتح هذا الدليل داخل واجهة الطرفية (مفاتيح الأسهم للتمرير، **Esc** للإغلاق). قائمة **Settings** يمكنها
إخفاء نقاط الاهتمام المدرجة أسفل الرسم البياني.

يمكنك رسم أي تعبير، بما في ذلك دوالك الخاصة. عرّف واحدة أولاً، ثم ارسمها:

```epher
def f(x) = x ^ 3
graph f(x)
```

كل سطر `graph` يضيف منحنى إلى المخطط، يُرسم برمزه الخاص (`o` أو `x` أو `+` أو `*`)؛ `graph clear` يفرغ المخطط. تنطبق القواعد نفسها كما في تطبيق الويب: مجال (`graph sin(x) from 0 to 2*pi`)، ومنحنيات وسيطية (`graph param 2*cos(t), 3*sin(t)`)، ومنحنيات قطبية (`graph polar 1 + cos(theta)`)، ومناطق (`graph y < x ^ 2` يظلّل المنطقة تحت المنحنى).

النقاط التي لا يكون للتعبير فيها قيمة (القسمة على صفر مثلاً) تُتجاوز ببساطة، تاركة فجوة في المخطط. بعد كل أمر graph يعرض TUI نقاط الاهتمام (الجذور ونقاط التحوّل والتقاطعات) تحت المخطط. أمر `table` (القسم 2.4.2) يعمل هنا أيضاً.

يرسم `graph3d x ^ 2 - y ^ 2` سطحاً 3D كإطار سلكي ASCII. دوّره بمفاتيح الأسهم ما دام الإدخال فارغًا، واضغط شريط المسافة لتحريك ثابت منزلق (القسم 2.4.5). يعرض سطر التلميحات أسفل الشاشة تلميحي الأسهم والمسافة فقط عند عرض سطح 3D أو منحنى قابل للتحريك.

يكتب `graph save plot.svg` المخطط الحالي كنفس صورة SVG التي يعطيها زر
**Copy SVG** في تطبيق الويب؛ ويحفظ `graph3d save file.svg` الإطار
السلكي ثلاثي الأبعاد من الزاوية التي تنظر إليها.

### 5.4 الحفظ والاستمرارية

يتشارك TUI تخزينه مع CLI: كل ما يُحفظ في أحدهما متاح في الآخر. تعيش الدوال والنصوص البرمجية والسجل وتفضيل اللغة في `~/.epher` (الفصل 4.6)، وأوامر `save` و`save script` و`language` نفسها تعمل هنا.

## 6. بياناتك وخصوصيتك

- **برنامج epher المثبَّت** (تطبيق سطح المكتب وCLI وTUI) يخزن الدوال والنصوص البرمجية والسجل واختيار اللغة محلياً في `~/.epher` (أو `EPHER_STORE_DIR`). لا يغادر شيء حاسوبك.
- **تطبيق الويب** لا يخزن شيئاً على القرص: السجل يدوم فقط ما دامت الصفحة مفتوحة. يمكن لتطبيق الويب العمل دون اتصال لأن متصفحك هو من يخزن الصفحة نفسها.

تنفذ الإصدارات الخمسة الحساب بالكامل على جهازك. لا يُرسَل أي شيء إلى أي مكان.
