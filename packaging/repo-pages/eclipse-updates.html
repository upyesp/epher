epher Eclipse update site

This is the Eclipse p2 update site for the epher plugin. Eclipse reads it; a browser has nothing to list here. The repository metadata is in content.jar and artifacts.jar.

Install

  1. In Eclipse, open Help > Install New Software and click Add.
  2. Paste this address as the location: 
    https://epher.org/eclipse/updates/
  3. Tick the epher entry and finish the wizard.

The plugin uses LSP4E and TM4E, which Eclipse resolves along with it, so there is nothing to install first. The language server itself is a separate binary: put epher-lsp on your PATH once and every .epher file you open gets diagnostics, hover, completion and the inline answers.
