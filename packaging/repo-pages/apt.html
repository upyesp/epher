epher apt repository

This directory is the apt repository for the epher desktop app. apt reads it; a browser has nothing to list here.

Install from this repository

curl -fsSL https://epher.org/apt/KEY.gpg | sudo tee /etc/apt/keyrings/epher.gpg >/dev/null
curl -fsSL https://epher.org/epher.sources | sudo tee /etc/apt/sources.list.d/epher.sources >/dev/null
sudo apt update && sudo apt install epher

Updates arrive with apt upgrade like any other package.

What is in here

  • dists/stable/: the signed package metadata apt fetches on apt update.
  • pool/main/e/epher/: the packages themselves, amd64 and arm64.
  • KEY.gpg: the signing key, also served at https://epher.org/apt/KEY.gpg.
